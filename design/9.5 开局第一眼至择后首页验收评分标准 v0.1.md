## 〇、三段是什么

| 段 | 玩家看见 | 现有入口 |
|---|---|---|
| **第一眼** | 清档后卷首，洞府第一息 | `#prologue-layer` |
| **择跟脚** | 人 / 妖（未开放种族只作剪影） | `kind: race_choice` |
| **首页** | 择定之后的主屏：洞府底、立绘、身份行、主按钮所在首页 | `#app` 主布局 |

清档顺序必须是：卷首第一眼 → 择跟脚 → 择后首页。违反 = 红线 X4。

## 一、红线（一票否决）

命中任一条 → 该次评分作废，得分栏写「红线」，不写 80 充数。

| # | 红线 | 怎么判 |
|---|---|---|
| X1 | CSS冒充成品 | 卷首/择跟脚/首页**主视觉**（底图、立绘、跟脚身份卡）不用已有金标图，只用 `linear-gradient` + `border-radius` 假装洞府或角色 |
| X2 | 半屏新旧混用 | 同一环节水墨底配 Q 立绘；或卷首跳到陈塘/骷髅旧气质图、首页却是新洞府 |
| X3 | 无封神锚点 | 纯通用仙侠；第一眼看不见洞府或榜文碎光；择跟脚看不出人/妖身份 |
| X4 | 流程错乱 | 清档后不是卷首第一眼，或跟脚被推迟，或跳过首页 |
| X5 | 第三种画风 | 另起与 9.2 金标冲突的审美（暗黑写实、扁平 iOS、贴纸表情包） |

红线至少这五条。X1–X3 对应用户指定的「CSS 冒充成品 / 半屏新旧混用 / 无封神锚点」。

## 二、百分制栏位

未触红线才打。五栏权重之和为 100。每栏打整数，**允许合计 94 以下**，禁止五栏全写满分凑 95。

| 栏 | 权重 | 评什么 | 满分长什么样 | 常见扣法 |
|---|---|---|---|---|
| A 第一眼 | 25 | 刚进来几秒 | 洞府画布是世界本身；天光、洞口、天上金卷（榜文碎光）一眼可指；文案是气息不是说明书 | 假卷轴卡片盖住洞府 −12；跳到别的地图 −10；只有字没有画 −15 |
| B 择跟脚 | 20 | 人/妖身份 | 两张身份卡，立绘是金标 Q 版；先点后立命；未开放种族不占半屏 | 电子表格三行成长/上限当主菜 −10；只有「人」「妖」圆钮无形象 −12 |
| C 首页 | 20 | 择后主屏舞台 | 同一洞府底 + 对应种族练气立绘 + 身份行写出跟脚；像从洞口走出来 | 择了妖仍显示人立绘 −12；底图与卷首不是同一洞府 −10 |
| D 套件一致 | 20 | 三段同一套 | 并排放卷首、跟脚卡、首页，能说「这是同一款 Q 版封神」 | 卷首奶油卡片、首页青绿山水 −10；人妖立绘不是一族 −8 |
| E 流程规格 | 15 | 顺序与可替换 | 清档 390 宽：卷首→跟脚→首页；文案仍是洞府第一息；后出图按 9.3 换层不换逻辑 | 走查顺序破了 −15；占位写死无法换图 −6 |

**判定：** 合计 ≥95 且无红线 → 通过。90–94 打回。&lt;90 或红线 → 废弃。

HUD 令牌/玉璧切图走 9.4，**不并进本表**。本表 C/D 看舞台（底+立绘+跟脚身份），不因主按钮仍是渐变胶囊而判 X1（X1 只绑主视觉底图/立绘/身份卡）。

### 3.1 第一眼（卷首）

不要再做一张「CSS 木轴假卷」盖在洞府上。玩家第一眼必须看见**那张洞府画**：洞口暖光、蒲团、香炉、天上金卷。

四息仍是文案节奏，全部停在同一洞府（禁止切陈塘关/骷髅山——那是后文，第一眼泄漏是 6.0 渐显的反面，也是 X2）：

1. 洞府 · 第一息 / 你睁开眼 — 画布全开，字在下三分之一。
2. 山野洞府 / 石壁一行字 — 仍是此洞，字换，光略亮。
3. 天际 / 那一点金光 — **同一张画**上强调天上金卷（榜文碎光），不换地图。
4. 开始 / 先把这一息稳住 — 「盘膝吐纳」落在洞口前。

轻触继续、跳过卷首、末幕「盘膝吐纳」保留。走查关键字不改：`你睁开眼` / `洞府` / `盘膝吐纳`。

### 3.2 择跟脚

卷首结束后立刻择跟脚（人/妖）。不要电子表格。

- 底仍是洞府。
- 两张身份卡：金标立绘 + 族名 + 一句天赋，不是成长/上限三行当主菜。
- 先点卡，再「立此为命」（不可逆）。
- 未开放种族一条剪影带。
- 选择器保持 `.choice-pick` / `.race-confirm-btn`，走查不破。

### 3.3 择后首页

`getCharacterPath` 已按种族换练气立绘。择定后首页必须是：洞府底 + 该族立绘 + 身份行含跟脚短名。像从卷首那一洞口走出来，不是进了另一款游戏。

「跟脚已定」仍是一句收束弹窗，然后才是首页。不叠第二套开场动画。

### 3.4 后出图清单（本目标不造正式切图）

出图时每张仍走 9.3，≥95 才入库。提示词必须带 9.2 风格锁。验收：390 宽与金标并排能说「同一款游戏」。
