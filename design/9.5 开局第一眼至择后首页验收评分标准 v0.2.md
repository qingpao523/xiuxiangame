# 9.5 开局第一眼至择后首页验收评分标准 v0.2

> 评的是「刚进来第一眼 → 择跟脚 → 择跟脚之后的首页」这一套，不是战斗、不是 HUD 切图波。
> 口径同 9.3 / 9.4：**满分 100，≥95 才通过**。命中红线不打百分制。120 是打磨方向，不是新量表。
> 金标对照：`design/references/9.2_风格定调_keyart_v1.png`、`web/assets/characters/char_cultivator.png`、`web/assets/backgrounds/bg_mountain_cave.jpg`。
> 卷首定帧走 `web/assets/opening/`，按 9.3 打分后入库；**不得覆盖**正式 `bg_mountain_cave.jpg`。
> v0.1 实现复评写 96：按本表硬尺子不成立，见 §七。本版重打。

## 〇、三段是什么

| 段 | 玩家看见 | 现有入口 |
|---|---|---|
| **第一眼** | 清档后卷首三息：洞内醒来 → 天上金卷 → 盘膝吐纳 | `#prologue-layer` |
| **择跟脚** | 人 / 妖身份卡 + 雾中未醒七尊剪影（可点出 lock_hint，不能选） | `kind: race_choice` |
| **首页** | 择定之后的主屏：洞府底、立绘、身份行、主按钮所在首页 | `#app` 主布局 |

清档顺序必须是：卷首第一眼 → 择跟脚 → 择后首页。违反 = 红线 X4。

走查关键字不改：`你睁开眼` / `洞府` / `盘膝吐纳` / `跟脚`。选择器不改：`.choice-pick` 只给人/妖卡，`.race-confirm-btn` 立命。雾中剪影用 `.race-fog-card`，禁止挂 `.choice-pick`。

## 一、红线（一票否决）

命中任一条 → 该次评分作废，得分栏写「红线」，不写 80 充数。

| # | 红线 | 怎么判 |
|---|---|---|
| X1 | CSS冒充成品 | 卷首/择跟脚/首页**主视觉**（底图、立绘、跟脚身份卡）不用定帧/金标图，只用 `linear-gradient` + `border-radius` 假装洞府或角色 |
| X2 | 半屏新旧混用 | 同一环节水墨底配 Q 立绘；或卷首跳到陈塘/骷髅旧气质图、首页却是新洞府 |
| X3 | 无封神锚点 | 纯通用仙侠；第一眼看不见洞府或榜文碎光；择跟脚看不出人/妖身份 |
| X4 | 流程错乱 | 清档后不是卷首第一眼，或跟脚被推迟，或跳过首页 |
| X5 | 第三种画风 | 另起与 9.2 金标冲突的审美（暗黑写实、扁平 iOS、贴纸表情包） |

红线至少这五条。X1–X3 对应用户指定的「CSS 冒充成品 / 半屏新旧混用 / 无封神锚点」。

## 二、百分制栏位

未触红线才打。五栏权重之和为 100。每栏打整数，**允许合计 94 以下**，禁止五栏全写满分凑 95。

| 栏 | 权重 | 评什么 | 满分长什么样 | 常见扣法 |
|---|---|---|---|---|
| A 第一眼 | 25 | 刚进来几秒 | 洞府画布是世界本身；三息换机位不换世界；天光、洞口、天上金卷一眼可指；文案是气息不是说明书 | 假卷轴卡片盖住洞府 −12；金卷铺满成奖状墙 −8；跳到别的地图 −10；只有字没有画 −15 |
| B 择跟脚 | 20 | 人/妖身份 + 未醒期待 | 两张身份卡，立绘是金标 Q 版；先点后立命；未开放种族剪影全可见、一点即出 lock_hint，不能立命 | 电子表格三行成长/上限当主菜 −10；只有「人」「妖」圆钮无形象 −12；锁定种族只剩字带看不见 −10 |
| C 首页 | 20 | 择后主屏舞台 | 同一洞府底 + 对应种族练气立绘 + 身份行写出跟脚；像从洞口走出来 | 择了妖仍显示人立绘 −12；底图与卷首不是同一洞府 −10 |
| D 套件一致 | 20 | 三段同一套 | 并排放卷首、跟脚卡、首页，能说「这是同一款 Q 版封神」 | 卷首奶油卡片、首页青绿山水 −10；人妖立绘不是一族 −8 |
| E 流程规格 | 15 | 顺序与可替换 | 清档 390 宽：卷首→跟脚→首页；文案仍是洞府第一息；后出图按 9.3 换层不换逻辑 | 走查顺序破了 −15；占位写死无法换图 −6 |

**判定：** 合计 ≥95 且无红线 → 通过。90–94 打回。&lt;90 或红线 → 废弃。

HUD 令牌/玉璧切图走 9.4，**不并进本表**。本表 C/D 看舞台（底+立绘+跟脚身份），不因主按钮仍是渐变胶囊而判 X1（X1 只绑主视觉底图/立绘/身份卡）。

### 3.1 第一眼（卷首）

三息，全部停在同一洞府世界（禁止切陈塘关/骷髅山）：

1. 洞府 · 第一息 / 你睁开眼 — 洞内机位，蒲团与香炉，字在下三分之一。
2. 天际 / 那一点金光 — 洞外机位，**天上那一卷空白金榜**，不是奖状墙。
3. 洞府 · 吐纳 / 先把这一息稳住 — 坐到蒲团前，「盘膝吐纳」落下。

轻触继续、跳过卷首、末幕「盘膝吐纳」保留。跳过钮不得压在金卷上。

### 3.2 择跟脚

卷首结束后立刻择跟脚（人/妖）。不要电子表格。

- 底仍是洞府。
- 两张身份卡并排：金标立绘 + 族名 + 一句天赋。
- 先点卡，再「立此为命」（不可逆）。
- 未开放七族剪影**全部可见**（两行），点出 `lock_hint`，不能立命。
- 选择器保持 `.choice-pick` / `.race-confirm-btn`。

### 3.3 择后首页

`getCharacterPath` 已按种族换练气立绘。择定后首页必须是：洞府底 + 该族立绘 + 身份行含跟脚短名。

「跟脚已定」仍是一句收束弹窗，然后才是首页。不叠第二套开场动画。

## 七、v0.1「96」作废

v0.1 实现复评把「复用 `bg_mountain_cave` + 撤掉假卷轴 + 人妖立绘卡」写成 96。用户当场否决：那不是 wow，锁定种族看不见，卷首仍乱，**最多 50**。

按本表硬尺子回打那一版（不改权重）：

| 栏 | 回打 | 理由 |
|---|---|---|
| A | 12 | 没有独立第一眼定帧，CSS 盖金标洞府，四息换字不换机位 |
| B | 11 | 人妖卡可用；锁定种族是一行字，点不开也看不见 |
| C | 19 | 首页当时已经是洞府+立绘 |
| D | 12 | 卷首和首页像两套手续 |
| E | 15 | 走查顺序当时是对的 |
| 合计 | 69 | 即使用户观感判 50，本表也不准再写 96 |

v0.1 方案自评 96、实现复评 96 **整表作废**，只留作反面教材。以 v0.2 §五 / §六为准。
