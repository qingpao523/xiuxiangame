> 生成 2026-08-22。用户指令：「碎片系统（专属/通用两类）、主城三级地图细化」。
> 关联：design/15.0/15.1/15.2（地图容器与渐进解锁）、design/9.2（美术风格锁）、design/数值规划与平衡待办（数值台账）。

## 一、碎片系统（专属 / 通用 两类）

### 1.1 资源模型

| 碎片 | 数据结构 | 含义 |
|---|---|---|
| **专属碎片**（per-treasure） | `state.treasure_fragments = { [treasure_id]: count }` | 某件法宝的定向碎片，集满 N 个直接合成**那件**法宝 |
| **通用碎片**（万能） | 复用现有 `treasure_shard`（resource_table 已有） | 万能碎片，10-20 个合成一次**抽奖**（随机法宝） |

> 专属碎片是新结构（state 字段，非 resource_id，因按法宝分键）；通用碎片复用 treasure_shard（不新增资源）。

### 1.2 产出来源

| 碎片 | 来源 | 说明 |
|---|---|---|
| 专属碎片 | **地图格子探索**（翻格发现）+ **隐藏 Boss**（稀有掉落） | 定向：掉的是某件法宝的碎片；越稀有的法宝碎片越难掉 |
| 通用碎片 | **镇魔塔**（里程碑奖励，已给 treasure_shard）+ **修炼挂机**（idle 小额产出） | 通用：稳定可得，攒够抽奖 |

### 1.3 合成规则

**专属碎片·定向合成**：
- 集满某法宝的专属碎片 N 个 → 直接合成该法宝（确定性，无随机）。
- N 按法宝品阶递增（凡品 N 小，神品 N 大）——「收集量大」体现在神品需更多碎片。
- 「暂不保底」：碎片掉落无保底机制（不累积必出），靠收集量自然门槛。

**通用碎片·抽奖合成**：
- 消耗 10-20 个通用碎片 → 一次抽奖，随机得一件法宝。
- **按阶段分层**：奖池按玩家境界段分层（炼气段奖池=低阶法宝，金仙段=高阶法宝）。
- **完全随机**：段内各法宝按权重随机。
- **高价值极低**：段内高品阶法宝权重极低，大概率出低阶法宝。

### 1.4 概率梯度（🔴待校准）

**专属碎片掉落梯度**（按法宝品阶，神品 1% 或 0.5%）：
| 法宝品阶 | 碎片掉率（探索翻格基准） | 合成所需 N |
|---|---|---|
| 凡品 | ~30% | 10 |
| 灵品 | ~12% | 20 |
| 仙品 | ~4% | 35 |
| 神品 | 1% 或 0.5% | 50 |

**通用碎片抽奖权重**（段内，🔴待校准）：凡品 60% / 灵品 28% / 仙品 10% / 神品 2%（高价值极低）。

### 1.5 数据/代码触点
- `state.treasure_fragments` 默认 `{}` + 归一化（save-manager.js）。
- 合成入口：扩展 synth_recipe_table（专属配方：cost={ [treasure_id]_fragment: N } → output_treasure）+ 通用抽奖配方（cost={ treasure_shard: 15 } → lottery）。
- 掉落接入：格子探索（design/15.x 探索系统）翻格掉专属碎片；镇魔塔里程碑（已给 treasure_shard）；修炼挂机小额 treasure_shard。
- UI：法宝合成面板（专属碎片进度条 + 通用抽奖）。

## 二、主城三级地图细化

### 2.1 三级结构

| 层 | 内容 | 现状 |
|---|---|---|
| L1 | 世界总图（四大部洲） | 已有（world-map.js，design/15.2） |
| L2 | 部洲详图（节点/古道/行进） | 已有（design/15.1） |
| **L3** | **主城内部（NPC 深度玩法）** | **新增（仅主城；野外地图用交互面板，不做 L3）** |

> 用户决策：野外地图（山野/骷髅山/十绝阵/黄河）用**交互式面板**（格子探索+遭遇+Boss），不需三级；**主城应该三级**，因有 NPC 深度玩法。

### 2.2 南赡部洲三主城（1.0 版本）

| 主城 | 定位 | 解锁 | NPC | 二级地图（L3 场景） |
|---|---|---|---|---|
| **陈塘关** | 新手主城 | 炼气（开局） | 李靖（总兵）/哪吒/殷夫人/太乙真人 | 总兵府·校场·集市·海岸 |
| **西岐** | 中期伐纣主城 | 地仙（伐纣主线） | 姜子牙/姬发/散宜生 | 相府·王宫·校场·集市 |
| **朝歌** | 后期敌都决战 | 真仙（敌都深入） | 纣王/妲己/闻仲 | 王宫·摘星楼·鹿台·市井 |

### 2.3 NPC 深度玩法（每主城）

| 玩法 | 说明 |
|---|---|
| **任务**（quests） | NPC 派发主线/支线任务（链式，接 design/4.0 九卷叙事），奖励资源/碎片/线索 |
| **交易**（trade） | 集市 NPC 买卖资源/碎片/材料（货币=功德 merit 或灵石） |
| **剧情**（story） | NPC 对话推进封神剧情（妲己线/哪吒线/姜子牙线），接 11 雾中地标隐藏地点 |
| **修炼加成**（cultivation） | 主城特定 NPC 给修炼 buff（太乙真人→炼丹加成；姜子牙→破劫成功率） |

### 2.4 数据/代码触点
- map_table：主城节点加 `is_city: true` + `city_scenes`（L3 场景列表）。
- 新表 `npc_table`：npc_id/name/city/scene/dialogue/quest_id/trade_goods/cultivation_buff。
- 新表 `quest_table`（或扩展 event_table）：任务链。
- world-map.js：主城节点点击 → 进 L3（city_scenes 渲染），非野外面板。
- UI：L3 场景渲染（场景背景 + NPC 列表 + 互动）。

## 三、实现分批

| 批 | 内容 | 优先 |
|---|---|---|
| **A** | 碎片系统：state.treasure_fragments + 专属定向合成 + 通用抽奖 + 掉落接入（探索/塔/修炼） | 高（机制清晰） |
| **B** | 主城三级：陈塘关 L3（NPC 李靖/哪吒/太乙 + 任务/交易/修炼加成）作 MVP | 中（需 NPC 框架） |
| **C** | 西岐 + 朝歌 L3 + 任务链 + 剧情线 | 后续 |

> 碎片系统（批 A）机制清晰可先做；主城三级（批 B/C）需 NPC/任务框架，工作量较大。
