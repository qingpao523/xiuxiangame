# 1.8 MVP 前 30 分钟与前 2 天沉浸交互全链路设计 v0.1

> **v0.2 纠偏（2026-08-22，主控 O1 锁定）**：旧文把前 30 分钟高潮写成「破真人劫 + 本命法宝」。该口径**作废**。  
> 新口径：**30 分钟只到炼气中段**；闭幕三件套 = **第一门术法 + 榜文碎光 + 山野妖首**；**真人劫 / 本命法宝改到第 1 天**；**不加速升重**。  
> 执行规格以 `design/1.9` v0.3 为准；实现计划见 `design/1.11`。下文凡写「30 分钟破真人劫」处，均已被本节取代。

## 一、文档目标

当前《封神修道录》MVP 已经能跑通基础数据循环：

闭关
领取收益
升重
破劫
机缘
术法
法宝
地图
地仙一重封顶

但当前体验存在明显问题：

玩家进来后主要是在点按钮、领数字、看资源增长。
页面结构像调试面板，不像高品质放置修仙游戏。
用户在线时没有足够交互，只能等待现实时间流逝。
快进半日虽然能测试流程，但破坏沉浸。
美术资源很多，但没有被组织成完整体验链路。
主页面分块感太重，不像现在高质量放置修仙游戏的主界面。

因此，本文件目标是重新定义：

1. 用户从进入游戏第一秒开始，到前 30 分钟的完整体验。
2. 用户从第 1 天到第 2 天，最终到达地仙一重的完整链路。
3. 主界面如何从“数据页”变成“高保真封神修行场景”。
4. 在线时玩家能做什么，不只是等现实时间。
5. 每个关键节点的弹窗、文案、交互、演出、反馈。
6. 已有美术资源如何进入主界面、弹窗、按钮、地图、破劫、法宝流程。
7. 到达地仙一重后，继续点击修炼时如何提示当前 MVP 已到尽头。

本文件给 Codex / AI 程序员使用时，应作为**交互与体验重构规格**，不是世界观文档，也不是单纯数值文档。

---

# 二、核心问题重新定义

当前 MVP 的问题不是“功能太少”。

真正的问题是：

```text
玩家没有经历修仙过程，只是在结算数值。
```

玩家没有强烈感受到：

我进入了一个封神大劫将起的世界。
我不是在点按钮，我是在山野洞府闭关。
我不是领取经验，我是在出关收束道行。
我不是升级数字，我是在炼气、悟法、破劫。
我不是随便选奖励，我是在功德护真灵和劫气搏命之间选择。
我不是换装备，我是在本命法宝择主。
我不是到达地仙数值节点，而是榜文照身未曾留名，成为榜外散修。

所以本轮改造的目标是：

```text
把“点按钮涨数字”改造成“吐纳、闭关、出关、游历、观榜、得机缘、择法宝、破劫成仙”的连续体验。
```

# 三、MVP 体验目标重新锁定

## 3.1 MVP 内容上限

当前 MVP 仍然只做到：

```text
炼气士一重 → 地仙一重
```

不新增完整封神榜系统。
不新增神位系统。
不新增宗门。
不新增弟子。
不新增真仙神通。
不新增天仙、金仙、大罗系统。

但是体验上必须做到：

玩家从第一秒就知道封神榜存在。
玩家前 30 分钟持续有事做，并且**亲手换过至少 3 种玩法**（吐纳 → 游历/斗法 → 术法改战斗）。
玩家前 30 分钟闭幕是「第一门术法 + 榜文碎光 + 山野妖首」，停在炼气中段，**不到真人**。
玩家第 1 天能完成“炼气后段 → 破真人劫 + 获得本命法宝”的第一个境界高潮。
玩家第 2 天能完成“破地仙劫 + 成为榜外散修”的第二个高潮。
玩家到达地仙一重后知道当前版本到此为止，但仍期待后续天仙、真仙、神通系统。

---

## 3.2 前 30 分钟目标

前 30 分钟不应该让玩家等待现实时间，也**不应该用加速升重把玩法层一笔带过**。

前 30 分钟的目标是让玩家感到「游戏怎么玩变了」，不是感到「数字涨得快」：

```text
新号进入
↓
吐纳周天（只教这一件）
↓
升至可出洞（炼气三重）
↓
第一次山野游历 + 遭遇/斗法
↓
自选第一门术法，并立刻用在下一场
↓
触发榜文碎光
↓
击败山野妖首（30 分钟闭幕）
```

前 30 分钟最终状态建议：

```text
境界：炼气中段（约四重～六重，以玩法课表走完为准，不以十重为准）
主术法：1 门（刚学会，用过一次）
本命法宝：无（第 1 天）
地图：山野妖患，山河图已见过
核心记忆点：我出过洞、我动手斗过法、我选过术法、我见过封神榜碎光、我打过山野妖首。
```

---

## 3.3 前 2 天目标

前 2 天目标是把 MVP 跑完整：

```text
第 0 天 / 前 30 分钟：
炼气中段。出洞、斗法、第一门术法、榜文碎光、山野妖首。不到真人。

第 1 天：
炼气后段 → 破真人劫 + 本命法宝择主，再进陈塘关外围、功德/劫气选择。

第 2 天：
真人十重，地仙破劫，榜文照身未留名，成为榜外散修。
```

第 2 天最终状态：

```text
境界：地仙一重
称号：榜外散修
解锁：地脉感应
解锁：法宝祭炼入口
解锁：骷髅山边界
MVP 提示：当前版本修行暂至地仙一重，天仙篇尚未开启。
```

# 四、主界面整体重构方向

## 4.1 主界面不再做“三段式功能面板”

当前页面的问题是：

资源区一块。
主角区一块。
按钮区一块。
看起来像调试工具。

新的主界面应参考高品质放置修仙游戏：

```text
一张高保真主背景
内容叠加在背景上
主角立绘位于画面中心或偏中下
顶部是封神榜/标题/天象
资源以浮层小组件呈现
主行动按钮突出
底部功能点用图标 + 小字
所有弹窗用高质量边框和背景
```

玩家进入后应该第一眼觉得：

```text
我进入了封神大劫边缘的修行场。
```

而不是：

```text
我打开了一个数据面板。
```

---

## 4.2 主界面层级

主界面建议按图层组织：

```text
Layer 0：全屏高保真背景图
Layer 1：环境光效 / 封神榜光 / 劫气黑雾
Layer 2：主角立绘
Layer 3：法宝悬浮 / 主角状态光效
Layer 4：顶部封神 banner
Layer 5：资源浮层
Layer 6：道行进度条
Layer 7：当前目标面板
Layer 8：主行动按钮
Layer 9：底部功能图标导航
Layer 10：修行日志浮层
Layer 11：弹窗层
```

注意：

主界面不能再像一个普通 UI 页面。
UI 应该压在美术图上，而不是把美术图塞进 UI 框里。

---

# 七、主行动按钮设计

## 7.1 主按钮必须只有一个

主界面不应该让玩家同时看到一堆同级按钮。

必须始终有一个最大的主行动按钮。

它决定玩家当前最应该做什么。

## 7.2 主按钮优先级

从高到低：

1. 有未处理机缘
2. 有本命法宝待选择
3. 当前可破劫
4. 当前可升重
5. 有离线收益可领取
6. 有在线短行动可执行
7. 默认继续闭关

## 7.3 主按钮文案

| 状态    | 主按钮文案       | 说明     |
| ----- | ----------- | ------ |
| 有机缘   | 天象有变，查看机缘   | 进入机缘弹窗 |
| 法宝待选  | 本命法宝择主      | 真人一重触发 |
| 可破劫   | 榜文垂光，开始破劫   | 十重后出现  |
| 可升重   | 道行已满，可升重    | 小境界提升  |
| 有离线收益 | 出关领取        | 收菜     |
| 可在线修行 | 吐纳周天 / 入定一轮 | 玩家在线操作 |
| 默认    | 继续闭关        | 无其他事件  |

# 八、底部功能按钮设计

## 8.1 不再用大方块按钮

底部功能应该是图标按钮，类似放置修仙手游：

```text
境界
游历
术法
法宝
机缘
洞府/设置
```

每个按钮：

图标
短文字
红点
锁定状态

## 8.2 未解锁按钮显示方式

未解锁按钮可以灰掉，但不要消失。
点击时提示：

```text
炼气士三重解锁游历
```

或者：

```text
真人一重解锁法宝
```

这样玩家知道后面有东西可期待。

## 8.3 底部按钮解锁表

| 功能    | 解锁              |
| ----- | --------------- |
| 境界    | 开局              |
| 游历    | 炼气士三重           |
| 术法    | 炼气士四重           |
| 机缘    | 炼气士六重           |
| 法宝    | 真人一重            |
| 破劫    | 对应十重时进入境界页      |
| 设置    | 开局              |
| Debug | 仅 Debug 模式或隐藏入口 |

# 九、在线短回合修行系统

## 9.1 为什么必须做

当前最大问题是：

```text
用户在线时只能等现实时间。
```

放置游戏可以有离线收益，但前 30 分钟不能让用户干等。

因此必须加入在线短回合修行。

这不是新增复杂系统，而是把“等待时间”包装成可点击的修行行为。

---

## 9.2 在线动作列表

### 动作一：吐纳周天

解锁：

```text
炼气士一重
```

按钮文案：

```text
吐纳周天
```

```text
10 秒
```


```text
你盘膝吐纳，运转一轮小周天。
山中灵气被缓缓牵引，化作一缕道行归入体内。
```

用途：

开局让玩家马上有事做。

# 十七、最终总结

当前版本的问题不是系统不够，也不是美术资源不够。

问题是：

```text
玩法行为没有被包装成修仙行为。
```

所以接下来不是继续加世界观，也不是继续堆数据表，而是把玩家前 30 分钟和前 2 天做成一条完整体验链路：

```text
第一秒：
我是山野炼气士。

第 1 分钟：
我吐纳周天，获得第一缕道行。

第 3 分钟：
我升重，解锁山野游历。

第 8 分钟：
我悟得第一门术法。

第 12 分钟：
我看到封神榜碎光。

第 20 分钟：
我悟得第一门术法，并在斗法里用过。

第 30 分钟：
我见过封神榜碎光，击败山野妖首。我还是炼气士。

第 1 天：
我炼气圆满，破真人劫，得到第一件本命法宝，再进入陈塘关外围。

第 2 天：
封神榜感应我，我破地仙劫，榜文照身未留名，成为榜外散修。

地仙一重后：
当前版本修行暂止，天仙篇尚未开放。
```

一句话目标：

**让玩家不是在领收益，而是在封神大劫边缘一步步修成榜外地仙。**

当前 MVP 要从：

```text
点按钮 → 数字涨 → 到地仙
```

改成：

```text
吐纳 → 入定 → 游历 → 悟术 → 观榜 → 机缘 → 破劫 → 法宝 → 陈塘 → 功德/劫气 → 榜文感应 → 地仙
```

玩家前 30 分钟必须记住三件事：

```text
我第一次修出道行。
我第一次看见封神榜。
我第一次破劫成真人并获得本命法宝。
```

玩家前 2 天必须记住三件事：

```text
我进入陈塘关外围。
我在功德和劫气之间做选择。
我破地仙劫，榜文照身而未留名。
```

一句话目标：

**让玩家不是在等收益，而是在封神大劫边缘一步步修成榜外地仙。**
