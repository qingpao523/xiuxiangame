## 三、生图与验收流程（本次执行口径）

1. **标准先行**：本文先于任何生图存在（✅ 本文件）。
2. **生图**：qodercli 子代理执行，doneai skill → `d.one::gpt_image_2_generate`（aspectRatio 9:16、n=1、纯文生图不带旧参考——干净验证新锁），prompt 用 23.0 §6 风格锁 v3 全文版。
3. **下载落盘**：`design/references/23.0_风格定调_keyart_v3.png`；必须 `file` 验证真 PNG 且 >100KB（CDN 曾返回 398B 的 NoSuchKey XML 错误页，见教训）。
4. **打分**：另一个 qodercli 子代理按本文红线+百分制打分，填评分卡。
5. **<98**：缺陷一句话 → 重出（最多 2 轮）；仍不过 → 换构图策略。
6. **≥98**：登记 9.3 §1 金标表（keyart_v3 替换 keyart_v1 行）、23.0 §七 验收档案、devlog。

## 五、教训登记

- **qodercli 子代理派发规则（用户 2026-08-31 指令）**：图片类任务（生图验收、打分、看图）必须指定有视觉能力的模型 `DeepSeek-V4-Flash`（`qodercli -m DeepSeek-V4-Flash`），非指定场景也默认用它；派到无视觉能力的模型会瞎打分。
- doneai 生成状态 5（成功）返回的 CDN URL 可能 OSS 未同步：`https://done.cdn.alibabadesign.com/2026-08-31/516f372cb81085af.png` 与 `…/6fd4297d7f8ed5fa.png` 生成后 10+ 分钟仍 404（NoSuchKey，398B XML）。下载必须重试循环 + `file` 验真；持续 404 则重新生成。第三次生成（uuid gpt-6255f39a339fb722）的 URL 一次 200 成功：`…/d5af429b0a9bc411.png`。
- 生图方自评不计入验收：r2 生图子代理自评 99，仍以独立评分员 100/100 为准。
- **qodercli 附件上限 5 张**（两极抽查 r4 评 6 张时报「too many attachments, only 5 allowed」）——多样本评分须拆批派发。
- **模型系统行为两条（两极抽查 5 轮 16 样本实证）**：①明亮/留白场景恒定漂移向半透明水洗（prompt 重彩强化语只能缓解不能根除，场景词汇重构——亮度改「晨光照射矿物色山面」、天空改「干净月白涂层」——才见实进）；②AI 会在光柱/角落自发画印章、署名、金色文字（杀劫极 r4_1、r5_2 两轮触发 R4 判废）——验收必须逐张放大复核。
- 多样本择优（n=4/6）救不了方向性错误（r4 与 r3 同 prompt，最优分反而更低）；改变场景语义才是有效变量（r5 留白/净空/零金全部首次达标）。
