# 境界命名映射对照表 v1.0

> 用途：消除「数据表命名」与「UI 显示命名」双轨制带来的跨文档沟通错位（实盘测试 #8）。
> 权威来源：`web/js/realm-manager.js` 的 `getPhaseRealmName(realm)`（R1-B 洪荒正统显示映射层）。
> 原则：**`realm_id` 与数据表 `major_realm` 一律不动，仅显示层改名。** 凡文档/策划/存档沟通，
> 涉及玩家可见名称时用「显示名」，涉及数据/代码/存档时用「realm_id / 数据表名」。

---

## 一、显示映射规则（getPhaseRealmName）

| realm_id 前缀 | 数据表 major_realm | minor_level | UI 显示名 |
|---------------|--------------------|-------------|-----------|
| `rq_` | 炼气士 | 1–3 | 炼精化气·N重 |
| `rq_` | 炼气士 | 4–6 | 炼气化神·N重 |
| `rq_` | 炼气士 | 7–9 | 炼神还虚·N重 |
| `rq_` | 炼气士 | 10 | 炼虚合道·凡境圆满 |
| `zr_` | 真人 | 1–3 | 地仙·初期·N重 |
| `zr_` | 真人 | 4–6 | 地仙·中期·N重 |
| `zr_` | 真人 | 7–9 | 地仙·后期·N重 |
| `zr_` | 真人 | 10+ | 地仙·圆满·N重 |
| `dx_` | 地仙 | 任意 | 天仙·初期 |
| 其他 | （fallback） | N | `{major_realm}{阶段label}·N重` |

> 注：`tx_`（数据表 major_realm = 天仙）目前无专属显示分支，落入 fallback，显示为「天仙{阶段}·N重」。
> 若后续天仙篇需要正式显示名，应在 `getPhaseRealmName` 增加 `tx_` 分支并同步本表。

## 三、相关代码索引

- 显示映射：`web/js/realm-manager.js` → `getPhaseRealmName(realm)`、`getPhase(realm)`、`PHASE_TIERS`（constants.js）
- 寿元：`web/js/realm-manager.js` → `getRealmLifespan(realm)`
- 天象/称号：`web/js/game.js` → `getWeather(state)`、`getTitle(state)`（按 major_realm 与 realm_id 判定）
- 数据表：`web/data/realm_table.json`（realm_id / major_realm / minor_level / required_daoxing_to_next / combat_power_base）

## 四、文档对齐约定

1. 旧文档（如 `playtest-report.md`）若使用「炼气士/真人/地仙」等数据表名描述玩家可见境界，
   应逐步替换为显示名，或在首次出现时标注「（数据表名：XX）」。
2. 新增策划/设计文档涉及境界时，**优先写显示名**，括号内附 realm_id（例：炼神还虚·7重 `rq_07`）。
3. 本表为唯一对照权威；如显示规则变更，须同步更新本表与 `getPhaseRealmName`。
