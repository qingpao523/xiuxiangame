## 〇、本轮要做什么

把游戏里**仍是旧水墨/写实**的可见素材，全部换成与定调图同一套 Q 版。地图屏（P1a）已是 Q 版，本轮**不重做**，只在并排金标时抽检；抽检漂了再单张返修。

原则：

1. **先过本标准，再替换文件。** 未打分、未满 95、未过红线的图，不得覆盖 `web/assets/` 正式路径。
2. **一屏原子替换**（9.2 §4）：同一屏幕涉及的素材必须同一波全部过 95 才上线，禁止半屏新旧混用。
3. **用户终评优先。** AI 初评可打回；用户说「这张能用」则该张画面分视为 ≥95，只补技术入库关。

## 一、金标（95 分长什么样）

打分时把新图和下面三张**并排放**。金标不是心情，是对照物。

| 金标 | 路径 | 标定 | 这一张定义了什么 |

| 定调图 | `design/references/9.2_风格定调_keyart_v1.png` | 96 | 世界气质：清透蓝白青金、Q 版 3–4 头身、封神榜金光、陈塘关海城 |
| 主角练气立绘 | `web/assets/_grok_art_test/p0_char_cultivator_q_test.jpg` | **96（用户 2026-08-22 确认完全能用）** | 角色立绘：同一张脸、青白金深衣、大拂尘、纯色可抠底、表情有戏 |
| 山野妖首 | `web/assets/_grok_art_test/p0_boss_001_yaoshou_q_test.jpg` | **95（用户确认能用）** | Boss：Q 版人形山妖、赤瞳、劫气紫雾、破旗无字、蹲姿、纯色底 |

**95 分的操作定义：** 把新图缩到 390 宽，和金标并排，不看文件名，能说出「这是同一款游戏的下一张」。说不出 → 该项「套件一致性」先扣到不及格。

Grok 出图默认 JPEG 实底。画面关过 95 之后，再做入库关（抠透明 / 压成原位格式）。**不要因为还是 JPEG 就把一张气质对的图打到 94。**

## 二、两道门（先红线，再打分）

### 门 1 · 红线（一票否决，不进入百分制）

命中任一条 → **判废重做**，分数栏写「红线 #n」，不写 80 分充数。

| # | 红线 | 怎么判 |
|---|---|---|
| R1 | 封神世界观破了 | 西式翅膀/板甲/哥特；现代物件；日系二次元脸；纯通用可爱仙侠、指不出封神锚点 |
| R2 | 风格锁破了 | 水墨写实、暗黑恐怖、3D 塑料、像素怀旧、贴纸小熊/表情包风 |
| R3 | 结构崩了 | 多指、错关节、器物融合、脸崩、放大到手机实尺寸糊成色块 |
| R4 | 有字 | 可辨认汉字、伪汉字、水印、logo、旗面写「山魔王」这类 |
| R5 | 认不出 | 390×844 下 1 秒认不出这是谁/什么（图标/Boss/NPC 从严） |
| R6 | 无锚定漂了 | 未用金标参考就出、和金标并排不像一套 |

### 门 2 · 百分制（满分 100，≥95 通过）

未触红线才打这五栏。每栏按「满分 / 常见扣法」打整数，**允许打到 94、90、70**，禁止五栏全写 19 凑 95。

| 栏 | 分 | 满分长什么样 | 扣分（可叠加，扣到 0 为止） |
|---|---|---|---|
| A 风格锁 | 30 | 3–4 头身、圆润大眼、清透明快、厚涂+边缘光，和金标同族 | 偏贴纸平涂 −8；色温偏昏黄厚重 −8；头身接近写实 −15；无边缘光/蜡像皮 −6 |
| B 封神主题 | 20 | 至少 1 个可指认锚点，且是画面主体：商周服饰/法器、榜文金、劫气紫、功德金、地标或典故 | 锚点只在角落贴了个纹 −8；完全通用仙侠 本栏 0 并改判 R1 |
| C 结构精度 | 20 | 手握得住器物、五官清楚、布料/金属/玉放大有东西 | 手飘在法器旁 −8；眼神空洞 −4；材质一抹平 −6 |
| D 套件一致 | 15 | 与金标 + 本波已过审图并排，线宽/Q 度/色不漂 | 单独好看、并排不像一套 −10；本波第 2 张起色相跳了 −8 |
| E 规格 | 15 | 比例对、主体完整、底可抠（纯色也算）、无字 | 构图裁掉脚/法器 −6；底脏边 −5；比例错（该 1:1 出了 16:9）−8 |

**判定：**

| 总分 | 结论 | 下一步 |
|---|---|---|
| ≥95 且无红线 | **通过** | 进入库关 |
| 90–94 | **打回** | 只改缺陷项，重出，重打分 |
| <90 或红线 | **废弃** | 不进返修队列，换提示词重来 |

入库关（画面已 ≥95 之后，替换文件前）：

1. 原位文件名、原位路径（9.2 §6），JS/CSS 零改。
2. 原 jpg 位继续 jpg；原 png 位必须透明通道干净（无白边黑边）。
3. 边长不低于现文件，避免 Retina 发糊。
4. 390×844 真机/模拟器看一眼主体仍在。

## 三、分类专项（过了百分制还要核这张清单）

专项有一条「必须」没做到 → 即使总分 96 也打回，记在评分卡「专项缺陷」。

### 3.1 角色立绘（主角三阶段、NPC）

- 必须：全身或膝上，3–4 头身；主角三阶段是**同一人**（脸、发型骨相锁定，只改服饰/气质/法器）。
- 必须：纯色或透明底，不画完整山水（主屏另有背景层）。
- 主角锚点：练气＝青白金深衣+大拂尘（金标）；真人＝陈塘风雷气质、服饰加金线甲片但不换脸；地仙＝榜外散修、淡金榜纹，仍是同一人。
- NPC 必须能 1 秒认出（哪吒风火轮/乾坤圈，杨戬天眼三尖两刃，子牙打神鞭/四不像意向，通天诛仙剑意向）。

### 3.2 Boss

- 必须：Q 版人形或神兽拟人，**不是**贴纸动物。
- 必须：劫气紫或该 Boss 的机制色（龙兵冷青、柏鉴鎏金、通天青紫、女娲五色克制、老君炉金+紫气）。
- 必须：旗/幡/纹饰无字。
- 山野妖首对照金标：赤瞳、破旗、紫雾、蹲姿。

### 3.3 场景背景（竖版 9:16）

- 必须：中部留角色/战斗 UI 空位，不把细节堆满胸口。
- 必须：清透蓝白青金（暗场景用青墨，不用焦茶做旧）。
- 必须：无字。榜文只许光卷，不许写「封神榜」。

### 3.4 图标（术法 / 法宝 / 资源 / 地图节点）

- 必须：同一套构图合同（法宝：圆底托 + 3/4 俯视 + 统一光源；术法：同一外圈；资源：同一容器感）。
- 必须：缩到 32px 仍认得出物件。
- 必须：无字。一套里不许一张实底一张线框。

### 3.5 UI 件（弹窗底 / 条 / 边框 / 按钮）

- 必须：可 9-slice（装饰在四角，边均匀），**画面里无字**（字由程序写）。
- 必须：色跟金标（金、朱砂、青），不是深褐水墨框。

### 3.6 VFX

- 必须：透明底、可循环或可单次播放的光雾，不带角色、不带字。
- 符号色：突破/升重＝功德暖金；机缘＝金+薄紫；劫＝紫。

## 四、出图与评分流程（每张都走，不许攒一批再打）

```
1. 写这张的任务卡：文件名、尺寸、分类、封神锚点、参考金标
2. 用金标作 image_edit 参考（禁止无参考裸生；地图已验证过锚定才稳）
3. 出图 → 对照红线
4. 打百分制，填评分卡（下节模板）
5. <95 或专项失败 → 缺陷一句话 → 重出（最多 2 次）；仍不过 → 换策略（改构图/拆部件）
6. ≥95 → 入库关（抠图/改格式/原位覆盖准备）
7. 本波全部过 95 → 一次性替换该屏 → 390×844 走查混用 → 写入本文档案表 + devlog
```

评分人：AI 初评必须写扣分理由（哪一栏扣了、扣几分、看见了什么）。用户可一票改判。
