## 三、测试用例（批次5 上线必跑）

### 3.1 canUseSpell 单元测试（断言表）
| 场景 | state.liupai | spell_type | 期望 |
|---|---|---|---|
| 试验期 | {chosen:null} | 任意（thunder/fire/weapon/soul/calamity/body） | true |
| 器修主系 | {chosen:'qi'} | weapon | true |
| 器修非 native | {chosen:'qi'} | soul | false |
| 器修五行分支已解锁 | {chosen:'qi',branch:'wuxing'} | thunder / fire | true |
| 器修五行未解锁 | {chosen:'qi',branch:null} | thunder | false |
| 器修 prestige 修体 | {chosen:'qi',prestige:['xiuti']} | body | true |
| 器修 prestige 未含 | {chosen:'qi',prestige:[]} | body | false |
| 魂修毒分支 | {chosen:'hun',branch:'du'} | soul（毒归魂 C4） | true |
| 劫修斩仙 | {chosen:'jie',branch:'zhanxian'} | calamity | true |

### 3.2 择派仪式集成测试
1. 真仙破劫（bt_003）成功 → 弹四选一卡片（器/体/魂/劫），含代表人物 + fantasy + 确认警告（"一世不可逆"）。
2. 选器修 → state.liupai.chosen='qi', chosen_at_realm='zx_01'；本命系同步=weapon（C7）。
3. 择派后配招界面：非 native 系（soul/calamity）灰显 + 锁；weapon 系可放。
4. 战斗 _applyGlobalMult：器系伤害 ×1.15（修被动 weapon_damage_bonus）；本命=weapon → 再 ×1.5。

### 3.3 分支解锁测试
1. 金仙（jx_01）+ 收集 5 件正五行法宝 → 器修·五行分支解锁，thunder/fire 系可放。
2. 太乙（ty_01）+ 混元珠机缘 → 器修·混元太极解锁，法宝终极 +25%。
3. 大罗（dl_01）+ 满主系 + 1 分支 + 跟脚 + 机缘 + 同伴 → prestige 修体解锁，body 系可放（杨戬式）。

### 3.4 边界与回归
- 旧档（无 liupai）加载 → 试验期行为 100% 不变（V1/V2）。
- 转世（远期）→ state.liupai 清空，可重选（当前版本不可逆，V7）。
- 妖族 + 器修 + 本命 weapon → 妖族本命同系 ×1.15（battle-engine-v2.js:636）与修被动叠加正确。
