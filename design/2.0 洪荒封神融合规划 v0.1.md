## 一、世界观定调（以钉钉原始设定为准）

- 时代：封神前夕，巫妖大战落幕，人族初兴。天庭缺人手，圣人要完杀劫，各方落子。
- 核心张力：**做棋子，还是做下棋的人**。
- 玩家身份演进：山野散修（MVP 已实现）→ 择势力入局 → 封神杀劫中站队 → 终局三路线（受封天庭 / 肉身成圣 / 混元逍遥）。
- 叙事基调：参考《师兄》，**稳中带皮**——表面礼数周全，骨子里步步为营。可以莽但要担后果，可以留后手把劫数算死。

## 二、境界体系融合方案

| 阶段 | 现网页版 | 目标版（洪荒正统） | 突破的封神场景内容 |
|---|---|---|---|
| 凡境 | 炼气士1-10重（前/中/后/圆满） | 映射为凡境：炼精化气→炼气化神→炼神还虚→炼虚合道 | 可全程挂机；破真人劫=洗凡尘浊气 |
| 地仙 | 真人1-10重→地仙一重（封顶） | 地仙初/中/后/圆满 | **地仙后必须择势力**（硬门槛，进入洪荒棋局） |
| 天仙→真仙 | 未实现 | 各分初/中/后/圆满 | 势力功法驱动突破；真仙三花初现、流派定型 |
| 金仙 | 未实现 | **核心分水岭** | **斩却三尸 + 三花聚顶 + 五气朝元** 多段仪式；封神榜残影挑战开启 |
| 太乙→大罗 | 未实现 | 十二金仙层 | 参与封神大计资格；大罗榜文炼化 |
| 准圣→混元 | 未实现 | 版本天花板 | 斩一/二尸；终局三路线抉择 |

破劫通用原则（贯穿所有轮次）：**破劫 = 前置因果链的总决算**，不是点按钮。
构成：剧情节点事件 + 护劫之物收集 + 功德/劫气（后期为业力/杀业）抉择 + 势力助力 → 成功率明细（基础/功德护持/法宝护身/地脉/势力功法/榜文牵引/劫气压力）。失败也是内容：劫火淬体 / 一缕真灵被榜文摄去（得神位碎片但逍遥进度-）。

## 三、种族/跟脚融合方案

- 开局改为**种族即跟脚**九选一（钉钉设定）：巫/人/妖/魔/鸿蒙凶兽/先天生灵/龙/凤/麒麟，各带天赋与势力条件修正。
- 与 design 1.2 跟脚等级（凡骨→混元根脚）合并：种族决定初始跟脚与成长偏向，机缘/功德/法宝可洗炼跟脚。
- Web 单机版先做简化 4 选 1（人族/妖族/先天生灵/麒麟——都是单机语境成立的），巫魔龙凤留给势力版本。

## 四、势力矩阵融合方案

- 地仙圆满后强制剧情「入局」：至少四择一——**阐教**（重跟脚/法宝最多/易卷杀劫）、**截教**（有教无类/阵法/异类归宿）、**天庭**（体制内/功德敕令）、**五庄观**（中立庇护/人参果）。
- 势力决定：突破功法来源、破劫方式差异（法宝护身/阵法抗劫/敕令庇护/人参果续命）、专属机缘池、封神杀劫立场。
- 贡献点+地位链（外门→真传→长老）做轻量化：单机以「师门任务=每日目标链」呈现。
- 封神杀劫：金仙层 PVE 封神战场（阐截对战站队），杀业累计触发天罚，表现优异可被"封神"（接受=受封路线，拒绝=逍遥路线伏笔）。

## 五、分轮路线图

- **R0（已完成 2026-07-22）：凡境好玩化** —— 游历事件化冒险（9 遭遇事件，斗/绕/探抉择）、斗法回合化（血条+催法+回合日志，Boss/遭遇通用）、每日山中异象（5 种轮换）、吐纳节拍（金光窗口完美吐纳）。
- **R1（已完成 2026-07-23）：种族选择 + 洪荒正统境界体系**
  - 开局种族选择（首期 4 选 1：人族/妖族/先天生灵/麒麟，天赋按 2.1 设定表）；
  - 境界体系切换为洪荒正统 10 大境 × 初/中/后/圆满：凡境（炼精化气→炼气化神→炼神还虚→炼虚合道）→地仙→天仙→真仙→金仙→太乙→大罗→准圣→混元圣人；
  - 现有存档/数据表映射：炼气士1-10重 → 凡境四小境，真人 → 地仙境，地仙一重 → 天仙境入口。
  - 落地说明：命名走 getPhaseRealmName 显示映射层，realm_id 与数据表 ID 未动；四族天赋挂点（道行乘区/破劫加成/斗法吞噬/伴生灵宝/机缘与灵光）全部生效。
- **R2（已完成 2026-07-23）：破劫因果链 + 地仙后择势力**（阐/截/天庭/五庄观，势力功法驱动突破）。
  - 落地说明：破劫成功率扩展为八行因果明细（含榜文牵引负行与先天道体行）；到达 dx_01（天仙·初期）后紧随「修行暂止」弹「入局」四选一，四势力各带被动护持与每日师门任务（action_table faction_id 过滤）。
- **R3：金仙仪式线**（三花聚顶/五气朝元/斩三尸；封神榜残影挑战）。
- **R4：封神杀劫与终局**（杀劫站队、杀业天罚、太乙/大罗/准圣、终局三路线）。
- 每轮完成标准：不使用调试手段可玩通该轮新增内容；所有关键行为有封神文案与演出；devlog 记录。
