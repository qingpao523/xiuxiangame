# 23.4 主屏 v3 重构 · 评分标准 v0.1

> 用户拍板：设计分 20% + 美术分 70% + 功能分 10%，整体方案 ≥95 分过线，**禁止自评，必须调 subagent（qodercli DeepSeek-V4-Flash）独立评**。

## 总分构成（满分 100 = 美术 70 + 设计 20 + 功能 10）

> 每个子项给出**评分锚点**：满分长什么样、扣到 0 长什么样。评分员对照锚点打整数分，再按权重折算。

---

### 一、美术分 70%（主导权重，决定成败）

> **立绘排除声明（用户拍板）**：主角立绘（char-img）是独立美术资产，由 doneai 生图产出、受生图模型客观限制（出不了工笔重彩人物），**不属于本次 UI 重构（DOM/CSS 构图）的评分范围**。故移除原 A4 立绘融合子项，美术分由 A1/A2/A3/A5 四项重新配权至 70。评分时**忽略立绘本身的渲染风格**，只评 UI 构件（匾额/玉璧/目标卡/道行槽/主按钮/导航牌/云台/天段/事段）的美术质量。

**A1 v3 风格一致性（20 分）**
- 20 分：UI 构件通体青绿重彩×工笔神魔壁画语言，不透明矿物厚涂质感，与 keyart_v3 金标同源。
- 14 分：主体是青绿重彩，但个别构件残留旧风格/质感不统一。
- 7 分：青绿重彩与旧风格/水彩/动漫混杂，风格打架。
- 0 分：UI 构件通体旧金褐、或水彩淡彩（触红线）。

**A2 设计元素运用（20 分）**
- 20 分：7 个 UI v3 素材（匾额/资源牌/玉璧/目标卡/道行槽/主按钮/导航牌/云台）全部按天然比例呈现、零拉伸变形、文字精准落在素材预留空地、不压装饰纹样。
- 14 分：多数素材到位，个别有轻微比例/落位问题。
- 7 分：多个素材被拉伸/裁切/文字压纹样。
- 0 分：素材普遍变形或大量未用 v3 素材（触红线）。

**A3 色彩协调（16 分）**
- 16 分：月白/暖纸/墨青/墨绿/石青/石绿六色统一和谐，金只出现在天命语境（破劫/功德/劫气），无脏色/无双色互搏/无发灰发雾。
- 10 分：色板基本统一，个别处偏色或轻微脏色。
- 5 分：色板混乱、多处脏色或金越界到非天命处。
- 0 分：通体脏色/严重双色互搏（触红线）。

**A5 整体视觉品质（14 分）**
- 14 分：UI 构件精致、有质感、有氛围，像"一幅会动的青绿长卷"上的金玉构件，拿得出手。
- 8 分：尚可，但精致度/氛围不足。
- 4 分：粗糙、像页游拼贴。
- 0 分：廉价、半成品感。

---

### 二、设计分 20%

**D1 构图布局（8 分）**
- 8 分：元素按设计元素重新组织（天·人·事·路），立绘为视觉重心，主次分明，**明显不是旧框架盒子堆叠**。
- 5 分：布局尚可，但仍有旧框架痕迹或主次不清。
- 2 分：基本是旧框架贴皮（触红线）。
- 0 分：完全是旧骨架堆叠。

**D2 信息层级（6 分）**
- 6 分：信息分组清晰、阅读顺序自然、重要信息突出。
- 4 分：层级基本清楚，个别信息主次模糊。
- 2 分：信息杂乱、无层级。
- 0 分：信息完全混乱。

**D3 视觉动线与留白（6 分）**
- 6 分：动线顺畅、留白舒服、比例协调，无堆叠过载/无真空带/无拥挤。
- 4 分：动线基本顺，个别处留白/比例欠佳。
- 2 分：动线乱、留白失衡（过载或真空）。
- 0 分：动线完全混乱。

---

### 三、功能分 10%

**F1 可读性（4 分）**
- 4 分：所有文字/数值对比度充足、字号合适、无截断、无溢出。
- 2 分：多数可读，个别对比度低或轻微截断。
- 0 分：文字普遍难读/截断。

**F2 交互元素（3 分）**
- 3 分：主按钮唯一且醒目、导航六牌清晰、锁定态明确、状态可辨。
- 2 分：交互元素基本清楚，个别模糊。
- 0 分：交互元素混乱/不可辨。

**F3 信息完整性（3 分）**
- 3 分：资源/目标/进度/状态/榜文感应齐全且正确呈现。
- 2 分：多数齐全，个别缺失。
- 0 分：关键信息缺失。

---

## 过线规则
- **加权总分 ≥95 过线**（美术70×得分率 + 设计20×得分率 + 功能10×得分率）。
- **红线一票否决**（任一触发即废稿，不论分数多高；**红线只约束 UI 构件，立绘已排除**）：①UI 构件旧金褐风格残留 ②UI 构件水彩淡彩质感 ③UI 素材拉伸变形 ④文字溢出装饰纹样 ⑤明显"旧框架贴皮"违和。

## 评审纪律
- **禁止自评**：设计方（主控）不得给自己打分。
- **独立 subagent 评**：调 qodercli DeepSeek-V4-Flash，读截图（主屏 414×896 + 面板态），逐子项对照锚点打分。
- **评分员必须输出**：每个子项分数+一句理由 → 三大项得分率 → 加权总分 → 红线逐条判定 → TOP 问题清单 → 是否过线 → 返修指路。
- 未达 95 → 按评分员指路返修，重评，直到 ≥95。
