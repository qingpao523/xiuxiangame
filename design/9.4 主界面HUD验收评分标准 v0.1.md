# 9.4 主界面 HUD 验收评分标准 v0.1

> **主屏可点控件的评分裁判。** 9.3 管立绘/场景/图标；本文管「玩家手指按下去的那一层」。
> 依据：用户 2026-08-22 实机截图「这些 UI 太 low 了，先搞个评分」。口径同 D4s：**满分 100，≥95 通过**；红线否决不打分。
> 金标对照：`design/references/9.2_风格定调_keyart_v1.png` + 已过审立绘/山河图（清透蓝白青金、云纹、金榜、玉）。

## 〇、为什么要单独立 HUD 分

9.3 的 A 栏是「3–4 头身、大眼」。主按钮没有头身，硬套会打出假 95。

主屏 HUD 的问题不是少一张贴图，而是 **CSS 圆角渐变冒充成品**：宣纸色块 + 金边 = 任何换皮页都能做出来，和定调图并排会像两款游戏。

原则：

1. **先过本文，再画/再改 CSS。** 未打分或 <95 不得把「新皮肤」当过关。
2. **字由程序写。** 按钮图、底栏格、进度槽里禁止烘焙「吐纳周天 / 境界 / 洞府」。
3. **一屏原子。** 目标卡、主按钮、连续修行、底栏六格必须同一波过 95 再一起上；不许只换立绘、控件还是渐变条。

## 一、评什么（主屏清单）

截图红框 + 同屏必评件：

| ID | 控件 | 选择器 | 要长成什么样（95） |
|---|---|---|---|
| H1 | 目标卡 | `#goal-panel` | 卷轴/玉牌底，四角云纹，可 9-slice；标题区留给程序字 |
| H2 | 主行动按钮 | `#main-btn` | 金玉令牌或榜文残简形，按下/进行中/可升重三态几何同一；字叠在空槽 |
| H3 | 底栏六格 | `#bottom-nav .nav-btn` | 同一套玉璧格；锁定=封雾+锁徽；注意=功德金点；格内无烘焙字（「境」由程序写） |
| H4 | 连续修行 | `#auto-toggle` | 同套小令牌，开/关两态只改光，不改外形 |
| H5 | 道行槽 | `#progress-bar` | 槽是画的金属/玉槽，填充是功德金，不是 CSS `border-radius` 一条 |
| H6 | 资源筹码 | `#resource-strip .res-chip` | 外框与 H3 同族；图标已走 9.3，框本身也要过本文 |

顶栏 `#top-banner` 已有横幅贴图，本波**抽检**；战斗配招框走 9.2 P0「战斗核心 UI」，不并进这一张表。

## 二、红线（一票否决）

| # | 红线 | 怎么判 |
|---|---|---|
| U1 | **CSS 冒充成品** | 主交互件（H1/H2/H3）只有 `linear-gradient` + `border-radius`，放大没有云纹/金边雕/宣纸纹 |
| U2 | **烘焙汉字** | 切图上能读出「吐纳」「境界」「洞府」或伪字 |
| U3 | **两款游戏** | 和立绘/山河图并排，3 秒内说不出同一套 Q 版封神 |
| U4 | **状态不可读** | 锁定格和可点格只差透明度；升重和吐纳按钮外形完全一样、只靠文案 |
| U5 | **现代扁平** | iOS 胶囊、Material 浮层、霓虹描边 |

命中任一条 → 该件 **废弃**，不写 70 分。

## 三、百分制（满分 100，≥95 通过）

| 栏 | 分 | 5 分级满分 | 本屏常见扣法 |
|---|---|---|---|
| A 材质工艺 | 30 | 宣纸/金/玉/云纹是画出来的，边可 9-slice | 纯色块 −15；只有 1px 金边 −10；塑料渐变 −12 |
| B 封神结构 | 20 | 令牌/卷轴/玉璧/云雷纹是控件的骨架 | 只是金色矩形 −12；完全通用卡牌 −20 改判 U3 |
| C 状态可读 | 20 | 默认可点 / 进行中 / 可升重 / 锁定 外形可辨，字仍是程序的 | 升重只换文案不换态 −10；锁格看不出锁 −10 |
| D 套件一致 | 15 | 与顶栏横幅、立绘金青、山河图云纹同一族 | 奶油白块立在青绿山水上像 PPT −10 |
| E 规格 | 15 | 390 宽下可点热区 ≥44px；拉伸不裂角；无烘焙字 | 六格挤成 8mm −6；角花随拉伸变形 −6 |

**判定：** ≥95 通过 → 入库（切图 + CSS 热区）。90–94 打回。&lt;90 或红线废弃。

## 五、过 95 的做法（出图约束，不是现在就画）

每件出 **切图**，CSS 只负责热区和程序字：

| 件 | 切图 | 态 |
|---|---|---|
| H1 | 横条 9-slice 卷轴底，中空 | 1 张（内容变、框不变） |
| H2 | 令牌按钮 | 默认 / 按下 / 进行中（暗金）/ 可升重（榜文金亮）共 4 张，外形同一 |
| H3 | 玉璧格 | 可点 / 锁定（封雾+锁）/ 注意（功德金点）共 3 张；六格共用 |
| H4 | 小令牌 | 关 / 开 |
| H5 | 玉槽 + 功德金填充条 | 槽 1 张，填充可 CSS 或 1 张可拉伸条 |
| H6 | 筹码外框 | 1 张 9-slice，图标继续用 9.3 资源图 |

提示词必带 9.2 风格锁 v2；**禁止**在图上写字。金标锚定 keyart。
