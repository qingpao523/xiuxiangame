## 〇、定位

AudioManager 是 Web Audio 单例，接口与素材无关——系统当下即可端到端运行（程序化合成回退）。
本文档定义**真实音频素材**的完整清单、调性规范、生产管线，使 AudioManager 从"能响"升级为"好听"。

**核心原则**：
- 国风五声音阶（宫商角徵羽）为旋律基底，避免西方大小调。
- 音色偏古琴/箫/磬/鼓/编钟，Q 版轻量感（非厚重交响）。
- 战斗音效清脆有反馈感，环境音留白不抢戏。
- 所有素材 ≤3s（SFX）/ 循环无缝（BGM），ogg 优先 mp3 兜底。

## 一、现有系统盘点（AudioManager 架构）

| 层 | 实现 | 说明 |
|---|---|---|
| 引擎 | Web Audio API 单例 | `AudioManager`（web/js/audio-manager.js） |
| 总线 | master / sfx / ambient / music | 独立增益，settings 持久化到 `state.audio` |
| 自动播放合规 | 首次手势（pointerdown/keydown/touchstart）后 init | 浏览器 autoplay policy |
| 可访问性 | prefers-reduced-motion 尊重 | 减弱闪烁类音效 |
| 素材加载 | `web/audio/{id}.ogg` → `.mp3` 优先 | 无素材回退程序化合成（SFX_RECIPES） |
| 默认音量 | master:0.8 / sfx:0.85 / ambient:0.45 / music:0.6 | 可设/可静音 |

### 2.3 文件规范

- 路径：`web/audio/{id}.ogg`（优先）/ `web/audio/{id}.mp3`（兜底）
- 格式：ogg vorbis 128kbps / mp3 128kbps，单声道（SFX）/ 立体声（BGM）
- 时长：SFX ≤3s（除 boss_enter ≤5s），BGM 循环无缝
- 命名：全小写下划线，与逻辑 id 一致
- 体积：单 SFX ≤100KB，单 BGM ≤2MB（H5 移动端流量敏感）

## 四、国风调性规范（对齐 D4 古典 Q 版）

### 4.1 音阶

- 五声音阶为主：宫(C) 商(D) 角(E) 徵(G) 羽(A)
- 避免半音（fa/si），避免西方功能和声进行
- 转调用"以变为宫"（清角/变宫）而非西方属七

### 4.2 乐器 palette

| 类别 | 乐器 | 用途 |
|---|---|---|
| 旋律 | 古琴、箫、笛 | BGM 主旋律 |
| 节奏 | 堂鼓、板鼓、木鱼 | 战斗/塔节奏 |
| 色彩 | 编钟、磬、风铃 | 提示音/破劫/机缘 |
| 弹拨 | 琵琶、中阮 | 战斗紧凑感 |
| 氛围 | 埙、笙 | 环境/离线/留白 |

### 4.3 Q 版轻量感

- 避免厚重交响/管弦全奏
- 单音色突出，混响短（山洞感 ≤1.5s RT60）
- 战斗音效清脆有"打击感"但不过重（Q 版非写实）
- 环境音留白 > 填充（道家"大音希声"）

## 五、素材生产管线

### 5.1 流程

1. **AI 辅助生成**：Suno/Udio 生成 BGM 草稿（提示词含"五声音阶/古琴/箫/宫调式/loop"）；SFX 用 freesound.org CC0 素材 + Audacity 剪辑
2. **人工校审**：逐条试听，确认调性一致/无西方和声/循环无缝/时长合规
3. **格式转换**：ffmpeg 转 ogg vorbis 128kbps + mp3 128kbps 双格式
4. **命名入库**：`web/audio/{id}.ogg` + `web/audio/{id}.mp3`，与逻辑 id 一致
5. **代码接入**：AudioManager.playSfx(id) / playAmbient(id) 调用点补齐
6. **验收**：逐条对照本文档 §2/§3 清单，确认触发正确/调性合规/体积达标

### 5.2 优先级排期

| 批次 | 内容 | 依赖 |
|---|---|---|
| P0（立即） | 9 个已有 SFX 真实素材 + bgm_main + bgm_battle | 无（并行轨） |
| P1（批次1-2） | 6 系战斗 SFX + combo + ultimate + boss_enter + bgm_boss + bgm_breakthrough | 九Boss接线后 |
| P2（批次3-5） | tower/liupai/alchemy/talisman SFX + bgm_tower + bgm_liupai + bgm_offline | 镇魔塔/流派上线后 |

## 六、验收标准（引 design/9.3 框架）

| 维度 | 权重 | 标准 |
|---|---|---|
| 素材完整性 | 25% | §2.1 全部 9 个 SFX 有真实素材（非合成回退）；§3 P0 BGM 2 首就位 |
| 调性合规 | 25% | 五声音阶/国风乐器/无西方和声/Q 版轻量感 |
| 触发正确 | 20% | 每个 id 在正确场景触发，无漏触发/误触发 |
| 技术合规 | 15% | ogg+mp3 双格式/体积达标/循环无缝/autoplay 合规 |
| 可访问性 | 10% | 静音/音量设置生效/prefers-reduced-motion 尊重 |
| 代码质量 | 5% | node --check 通过/无内存泄漏/AudioContext 正确回收 |

**硬性否决**：任何素材含西方大小调和声 / 体积超限 / 循环有接缝 / autoplay 违规。
