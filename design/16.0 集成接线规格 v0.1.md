## 一、批次0 · 九Boss引擎接线（contested：battle-engine-v2.js / battle-ui-v2.js / game.js / index.html）

### 1.1 机制委托（battle-engine-v2.js）
两个钩子 `_processMechanicTurnStart(state,battle,events)` / `_processMechanicEnemyPhase(state,battle,events)` 的 `switch(battle.mechanic)`：
- 9 个新 key 各加 case 委托，或在 `default` 统一委托：
  - turnStart 类（zhangguifang_interrupt / shiji_parasol / mo_lihai_strings / huoling_burnstack）→ `BossMechanicsV2.dispatch("turnStart", state, battle, events)`
  - enemyPhase 类（aobing_transform / mo_liqing_sword / mo_lihong_umbrella / luoxuan_fivefire）→ `BossMechanicsV2.dispatch("enemyPhase", state, battle, events)`
- **战斗创建**（create）末尾调 `BossMechanicsV2.init(state, battle)`（铺 mechanicState；花狐貂 init 设 enemy.block=30%hpMax）。
- **玩家伤敌后**（_dealDamageToEnemy 之后）调 `BossMechanicsV2.onPlayerDamageDealt(state, battle, enemy, rawDmg, events)`（八卦云光帕累积破罩 / 花狐貂护甲吸收→暴怒）。
- **敌方攻击时**（executeEnemyRound 的 attack 分支）调 `BossMechanicsV2.onEnemyAttack(state, battle, enemy, events)`（火灵灼烧叠层+引爆）。
- ⚠️ 委托必须用 `handler.call(BossMechanicsV2, ...)`（this 指向顶层单例，否则 `this._setSlotCd` 未定义——tests 已验证此契约）。

### 1.2 per-slot 冷却子系统消费（battle-engine-v2.js）

## 二、批次3 · 镇魔塔 runner（contested：save-manager.js / game.js / ui.js）

```js

tower_best_floor_ever: 0, tower_total_kills: 0, tower_floor_clears: {},
```
加载归一化块（~L100-184）加 `state.tower = state.tower || {...}` 等。`TOWER_TICKET_CAP=3`（constants.js）。

### 2.2 周期重置（game.js / unlock-manager.js）
`_resetTowerCycleIfNeeded(state)`：`cycleIndex = Math.floor(epochDay/2)`，`epochDay = Math.floor(Date.now()/86400000)`；mirror `unlock-manager.js:123 _resetDailyIfNeeded`（key state.last_daily_reset_day === todayString()）。新周期 → tickets 重置为 TOWER_TICKET_CAP，current_floor/best_floor_this_cycle 归 0。

### 2.3 爬层流程（game.js，design/12.0 §七）
- `startTowerRun()`：校验 tickets>0 + in_run=false → in_run=true，current_floor=1，发起首层战斗（source:"tower"）。
- `_nextTowerFloor()`：current_floor++，读 tower_table.json 该行 → cfg.enemy_power = boss.recommended_power × power_mult；连战层（boss_026 chain）按 chain_order 顺序。
- `_endTowerRun(win)`：胜→结算 reward（_applyResourceDelta；milestone_reward 段末层；tower_ticket 单独 +state.tower.tickets 非 _applyResourceDelta）+ tower_floor_clears[floor]++ + tower_total_kills++ + best_floor_this_cycle/ever 更新；败→in_run=false 保留 best。
- **不消耗 Boss 日限**：塔击杀不计 boss_counts_today（design/12.0 §2.3）。

### 2.4 finishBattle source:"tower" 分支（game.js）
参照 boss 分支（~L562-603）：win→reward + _nextTowerFloor（继续爬）或 _endTowerRun；loss→_endTowerRun(false) + 安慰。

### 2.5 UI（ui.js）
