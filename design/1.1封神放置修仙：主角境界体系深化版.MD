# 封神放置修仙：主角境界体系深化版

## 一、核心境界表

游戏主境界采用九境：

| 阶段   | 游戏境界 | 世界观解释        | 玩家感受      |
| ---- | ---- | ------------ | --------- |
| 凡修成道 | 炼气士  | 初窥大道，会法术，会御器 | 刚入修行，快速升级 |
| 凡修成道 | 真人   | 炼成道体，可斩妖除魔   | 从凡人变成真正修士 |
| 凡修成道 | 地仙   | 脱离凡俗，寿元大增    | 开始有仙人味    |
| 仙道登阶 | 天仙   | 道行大成，可腾云入天   | 进入封神战场    |
| 仙道登阶 | 真仙   | 三花初现，神通圆满    | 技能成型，战力爆发 |
| 仙道登阶 | 金仙   | 三花聚顶，五气朝元    | 成为封神级强者   |
| 大道超脱 | 太乙   | 掌握大道神通       | 可对抗榜上正神   |
| 大道超脱 | 大罗   | 跳出因果，不入轮回    | 反压封神大劫    |
| 大道超脱 | 混元   | 与天地同寿，逍遥不灭   | 终极境界      |

这套体系有几个优点：

第一，**简单**。玩家不用理解复杂术语，一看就知道炼气士低、金仙高、大罗很强。

第二，**符合封神气质**。里面有炼气士、真人、地仙、天仙、金仙、太乙、大罗、混元，这些词都比“元婴、化神、炼虚”更贴近封神神话语感。

第三，**适合放置数值**。每个大境界可以拆成十重，玩家不断突破，爽感稳定。

---

## 二、三段结构

这九个境界不要平铺，要分成三大阶段。

## 第一阶段：凡修成道

包含：

炼气士
真人
地仙

这一阶段的核心体验是：

**从凡人修成仙。**

玩家还不是大能，也不是封神战场的主角，只是在大劫边缘慢慢成长。

这一阶段的爽点应该是：

升级快。
突破频繁。
不断解锁新法术。
从打小妖到斩妖王。
从会符箓到能御器飞行。

第一阶段的地图可以是：

山野妖患
陈塘关外围
骷髅山边界
东海荒礁
西岐古道

这一阶段不需要让玩家接触太深的阐截大战，只需要让玩家知道：

**封神大劫快来了，我要先变强。**

---

## 第二阶段：仙道登阶

包含：

天仙
真仙
金仙

这一阶段的核心体验是：

**从普通仙人变成封神级战力。**

玩家开始真正进入封神战场。

不再只是打野怪，而是接触：

阐教弟子残影
截教阵法残痕
商周战场劫气
法宝碎片
神位榜文
杀劫试炼

这一阶段的爽点是：

法宝开始成型。
神通开始进阶。
战斗特效变大。
可以挑战封神人物残影。
开始获得封神榜碎片。

这一阶段的地图可以是：

九龙岛
西岐战场
汜水关
十绝阵外围
黄河阵残域

这一阶段最重要的是**金仙**。

金仙应该是游戏中第一个大高潮。

突破金仙时，不只是数值提升，而是告诉玩家：

**你已经不是普通散仙，你正式进入封神强者层。**

---

## 第三阶段：大道超脱

包含：

太乙
大罗
混元

这一阶段的核心体验是：

**不入封神榜，反过来掌握大劫。**

玩家已经不是被大劫推着走的小修士，而是可以利用大劫、挑战神位、炼化榜文、对抗天命的强者。

这一阶段的爽点是：

可以挑战高阶封神榜残影。
可以炼化先天灵宝残影。
可以破十绝阵、九曲黄河阵、万仙阵。
可以选择是否受封神位。
可以走“肉身成圣”或“混元逍遥”路线。

这一阶段地图可以是：

九曲黄河阵
万仙阵外围
诛仙阵残境
封神台
天庭神位试炼
混元道场

这一阶段的最终追求不是“飞升”，而是：

**不入榜，不受封，自成大道。**

# 三、大境界与小境界

为了适合放置游戏，每个大境界拆成十重。

例如：

炼气士一重
炼气士二重
炼气士三重
……
炼气士十重

突破后进入：

真人一重

这样玩家一眼能懂，也方便做数值。

完整结构是：

```text
炼气士一重 ~ 炼气士十重
真人一重 ~ 真人十重
地仙一重 ~ 地仙十重
天仙一重 ~ 天仙十重
真仙一重 ~ 真仙十重
金仙一重 ~ 金仙十重
太乙一重 ~ 太乙十重
大罗一重 ~ 大罗十重
混元一重 ~ 混元十重
```

每一重是小成长。
每十重突破一次大境界。
每次大境界突破都要有强烈动画和文案。

# 六、资源命名

主经验不要叫“经验值”。

建议叫：

```text
道行
```

因为“道行”非常封神，也很好懂。

玩家挂机获得：

道行
法力
功德
劫气
法宝碎片
神通残页

其中：

道行 = 升境界
法力 = 战斗基础数值
功德 = 稳定成长、降低失败
劫气 = 高爆发、高收益
法宝碎片 = 合成法宝
神通残页 = 升级技能

上线结算可以写成：

```text
闭关结束！

你参玄悟道三百年。

获得：
道行 +300 年
法力 +12.5 万
功德 +8000
劫气 +3200
法宝碎片 ×16
神通残页 ×5

当前境界：
真人七重 → 真人九重
```

这样既有封神味，又简单。

# 七、突破条件

每个小境界只需要：

```text
道行达到要求
```

每个大境界突破需要：

```text
道行达到要求
突破丹 / 功德 / 法宝护身
通过杀劫
```

但这里不要做复杂。

可以简化成三项：

```text
道行
功德
破劫成功率
```

例如：

```text
突破：真仙十重 → 金仙一重

需要：
道行：100%
功德：足够
破劫成功率：85%

可突破
```

点击突破后，如果成功：

```text
金仙道果凝成！
```

如果失败：

```text
破劫失败，但道行未失。
获得劫雷淬体，下次突破成功率 +10%。
```

放置游戏里，突破失败不能太伤。失败也要给成长。

# 八、和封神背景的关系

这套境界不是照搬某一本书，而是为封神放置游戏设计的。

封神背景里的元素这样挂载：

## 阐教

提供：

正统道法
雷法
金仙传承
法宝祭炼
功德护体

适合稳健玩家。

## 截教

提供：

阵法
劫气
妖仙神通
群攻技能
强力法宝残影

适合高收益玩家。

## 天庭

提供：

神位
香火
敕令
雷部、火部、斗部等后期路线

适合稳定收益玩家。

## 封神榜

提供：

挑战目标
神位碎片
榜文残页
终局压力

玩家最终目标不是上榜，而是：

**不入封神榜，自己成道。**

# 九、最终总结

这套境界体系可以定为：

```text
炼气士
真人
地仙
天仙
真仙
金仙
太乙
大罗
混元
```

每境十重。

主经验叫：

```text
道行
```

大突破叫：

```text
破劫
```

核心爽感是：

```text
挂机涨道行
道行升境界
境界开法宝
法宝强神通
神通推封神
破劫成金仙
最终不入榜
混元得逍遥
```

一句话定义：

**这是一个无名炼气士，在封神大劫中挂机修道、祭炼法宝、积累功德、破除杀劫，最终从炼气士一路成长到混元逍遥的主角成长型放置修仙游戏。**
