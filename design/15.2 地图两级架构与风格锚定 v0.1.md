## 一、问题收敛（第一性原理）

玩家打开地图的第一判断是"这是一个完整世界"，不是"这里有五个色块"。当前实现的三个根因：

1. **五张独立部洲图拼贴** → 每张各自生成、各自构图，拼在一起必然割裂；且未解封部洲被灰化+fog 后呈灰黑块，与全彩南赡部洲并置 = "只有南赡是动漫风"。
2. **提示词失控**：15.1 批次提示词大量堆"米黄/暖金/高饱和"，把整体推向厚重暖调，偏离 keyart_v1 定调图的**清透蓝白青金、空气感、亮高调**（9.3 规定套件一致性以 keyart_v1 为锚，批次未锚定 = 流程失误）。
3. **交互无层级**：可玩节点（map_001~009）与 flavor 地标混摆一屏，密集重叠，既无世界感也无旅程感。

## 二、两级架构（L1 世界总图 → L2 部洲详图）

### 2.1 L1 世界总图（一级页面）

- **底图：单张统一世界地图**（一张图生成全部五部洲）——魔兽世界式"一个世界"观感：形状各异的区域在一张图内以云海/山脉/海峡自然拼接，同一片天空与光照，色彩天然统一。不从代码拼五块。
- **只标部洲 + 关键位置**（用户指定）：
  - 北俱芦洲：北荒妖族（招妖幡）
  - 西牛贺洲：西天灵山
  - 东胜神洲：傲来国·花果山
  - 南赡部洲：关键位置（洞府=家、朝歌=伐纣终点远景）
  - 须弥昆仑中枢：**只标封神台**（其余不标）
- **部洲级封印锁（保留，用户点名好评）**：未解封部洲罩**轻纱金雾 + 金色锁徽**（不再灰黑块——锁徽沿用现有 CSS 锁形，雾改为亮色薄纱，保持整图色调统一）。
- **交互**：点击已解封部洲 → 展开进入该部洲 L2；点击封印部洲 → 锁徽抖动 + toast（"此处封印未解，随境界渐开"）。中央封神台未解锁前同样带锁。
- **当前位置**：L1 上玩家所在部洲给乘云小仙标记（marker 复用）。

### 2.2 L2 部洲详图（二级页面）

- 点击部洲后**整屏切换**到该部洲详图（复用 15.1 批次已入库的五张部洲底图作全屏底，边缘羽化不再需要）。
- L2 承载 15.1 全部动态体验：可玩节点 5 态（sealed/locked/available/current/completed）、伐纣古道逐段点亮、行进标记、破境 reveal（fog 碎裂+colorize+节点浮现+命名弹幕）。
- 节点坐标换算：世界坐标 (wx,wy) → 部洲内子坐标 `(wx-部洲框x)/部洲框w`，数据零改动。
- 顶部：部洲名 + 返回 L1；无可玩节点的部洲（西牛/北俱）显示地标剪影 + "尚无历练之地，权作远观"。

### 2.3 导航与 reveal 归位

- 破境 reveal 分两层：部洲解封 → L1 播放（锁徽碎裂+金雾散去）；节点新解锁 → 下次进入对应 L2 时播放（节点浮现+弹幕）。快照沿用 `state.flags.world_map_snapshot`（增加 L1 部洲层）。
- 入口不变：`world-map-btn` / popup `world_map` → 打开 L1。

## 三、风格锚定纠偏（所有新生图执行）

1. **参考图锚定**：gpt_image_2 支持 `imageUrls` 参考图——新生图一律把 `design/references/9.2_风格定调_keyart_v1.png` 上传后作为参考图传入（done-cli upload 取 URL），把"套件一致性"从文字描述变成像素级锚定。
2. **提示词调色**（对齐 keyart_v1 的清透感）：主色**清透蓝白青金**（蓝天、白云、碧海、青山、白玉金饰），暖金只作点睛（榜文/佛光/封印光）；**禁止**"米黄做旧/大面积暖金云海/厚重油画感"这类把画面推向昏黄的措辞；强调"亮高调、空气感、远景清透"。
3. **负面清单增补**：不要昏黄做旧、不要厚重油画、不要割裂拼贴。
4. 已有 15.1 批次（5 部洲底图/9 节点/11 地标/背景）继续使用但记录风格偏差；L1 统一底图先按新锚定出图，L2 部洲底图后续按同锚重出一版替换（同文件名覆盖，代码零改动）。

## 五、验收（追加 15.1 §五）

- L1 一眼是"一个完整世界"：无缝拼合、色调统一、无灰黑块；
- L1 无小地图节点（陈塘关外围等只出现在 L2）；
- 封印锁保留且清晰；点击已解封部洲进入 L2，L2 内 5 态/古道/reveal 不衰减；
- 新图与 keyart_v1 并置：色调/光影/气质一眼同套（9.3 套件一致性维度）。
- 附带修复：`当前驻留：undefined`（DataManager.getById 未命中返回 `{}` 为 truthy 所致，footer 改判 `map_name`）。
