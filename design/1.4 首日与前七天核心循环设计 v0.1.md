# 1.4 首日与前七天核心循环设计 v0.1

> **⚠️ 2026-08-22 作废为前 7 天权威。** 本文是单机一周通关剧本（第 7 天地仙、战斗只做结算、线性目标）。已被主控 **E1/E2/O4** 与 `design/1.12` 取代：手游多环 + 内容引擎 + 第 7 天不以到地仙为及格。保留本文仅作历史对照。

## 一、文档目标

本文件用于把《封神修道录》从“世界观 + 系统方向”推进到“可开做的前期玩法设计”。

本版本只覆盖：

炼气士一重 → 地仙一重

也就是玩家从初入修行，到第一次真正脱离凡俗、成为地仙的完整前 7 天体验。

本阶段不展开大后期，不展开完整封神榜，不展开神位系统，不展开真正神通系统。

本阶段核心目标是打穿四个爽点：

1. 闭关收菜爽
2. 境界提升爽
3. 机缘选择爽
4. 本命法宝爽

玩家必须在前 30 分钟觉得：

“数字涨得好爽。”

在第 1 天觉得：

“我真的修起来了。”

在第 7 天觉得：

“我已经有仙人味了，我想继续玩到真仙看神通。”

## 二、核心设计原则

### 1. 前期不叫神通

前期术语统一如下：

| 阶段   | 技能称呼        | 说明                 |
| ---- | ----------- | ------------------ |
| 炼气士  | 法术 / 小术     | 初学符火、雷法、御器         |
| 真人   | 术法 / 道术     | 法术稳定成型，可自动施放       |
| 地仙   | 成熟术法        | 术法与地脉、法宝开始结合       |
| 天仙   | 流派术法        | 法术开始出现明显路线倾向       |
| 真仙   | 神通          | 法术进阶为真正神通          |
| 太乙以后 | 大道神通 / 规则能力 | 神通具备镇压、削境、破阵、斩因果效果 |

因此，前 7 天所有产出里不出现“神通残页”。

前期统一使用：

法术残页
术法残页
法器碎片
法宝碎片
宝材
道行
法力
功德
劫气

“神通残页”从真仙阶段以后再开放。

## 三、前 7 天核心循环

前期主循环采用：

闭关收菜为主，机缘选择为辅，战斗只做结算表现。

完整循环为：

```text
离线闭关
↓
上线领取道行、法力、材料
↓
道行暴涨
↓
小境界提升
↓
触发机缘
↓
选择稳健收益或高爆收益
↓
获得法术残页 / 法宝碎片 / 功德 / 劫气
↓
强化术法或法器
↓
准备破劫
↓
突破大境界
↓
进入新地图
↓
下线继续闭关
```

玩家每日上线目标控制在 2 到 5 分钟。

上线不是打工，而是领奖。

## 八、放置收菜数值循环

### 1. 基础公式

离线收益公式建议为：

```text
离线道行 =
基础道行产出 × 离线分钟 × 境界倍率 × 地图倍率 × 跟脚倍率 × 法宝倍率 × 机缘倍率
```

为了方便前期调试，可以先做简化公式：

```text
离线道行 =
基础产出 × 离线分钟 × 总倍率
```

总倍率由以下部分组成：

```text
总倍率 =
境界倍率
+ 地图倍率
+ 跟脚倍率
+ 法宝倍率
+ 临时机缘倍率
```

前期不要做乘法过多，否则数值膨胀失控。

建议前 7 天多数倍率用加法叠加。

---

### 2. 离线收益上限

离线收益必须有上限，但前期不要卡太死。

建议：

| 阶段   | 默认离线收益上限 |
| ---- | -------- |
| 炼气士  | 4 小时     |
| 真人   | 8 小时     |
| 地仙   | 12 小时    |
| 天仙以后 | 逐步提升     |

第 1 天可以通过新手福利临时给 12 小时上限，避免玩家错过收益。

## 十、功德与劫气：稳 vs 爽

功德和劫气不是两种普通货币，而是两种成长态度。

### 功德路线

特点：

更稳。
破劫成功率高。
失败风险低。
适合轻松放置玩家。

示例效果：

```text
功德 +500
破劫成功率 +5%
下次机缘出现护身选项概率 +10%
```

### 劫气路线

特点：

更爽。
收益更高。
战力更猛。
但破劫压力增加。

示例效果：

```text
劫气 +500
游历收益 +10%
法器掉落 +10%
破劫压力 +3%
```

### 设计原则

前期劫气不能惩罚太重。

劫气主要让玩家感到“我更猛了”，而不是“我被坑了”。

前 7 天建议：

```text
每 100 劫气 = 游历收益 +1%
每 100 劫气 = 破劫成功率 -0.3%
劫气带来的破劫扣减前期最多 -15%
```

功德建议：

```text
每 100 功德 = 破劫成功率 +0.5%
功德加成前期最多 +20%
```

## 十一、机缘事件池

### 1. 机缘定位

机缘是前期灵魂。

机缘必须让玩家产生：

“我这次上线好像撞运了。”

机缘不能只是文案奖励，必须能改变成长路径。

---

### 2. 机缘触发来源

| 来源     | 触发方式       |
| ------ | ---------- |
| 离线闭关   | 收菜时概率触发    |
| 境界提升   | 升到关键重数时触发  |
| 游历地图   | 结算时概率触发    |
| 小 Boss | 首次击败必触发    |
| 破劫     | 成功或失败都可能触发 |
| 每日登录   | 每日首次收菜保底触发 |

---

### 3. 每日机缘上限

| 天数      | 机缘上限           |
| ------- | -------------- |
| 第 1 天   | 3 次            |
| 第 2 天   | 4 次            |
| 第 3 天以后 | 5 次            |
| 月卡 / 特权 | 可增加上限，但不影响核心体验 |

---

### 4. 机缘稀有度

| 稀有度  | 概率   | 说明                   |
| ---- | ---- | -------------------- |
| 普通机缘 | 70%  | 道行、法力、残页             |
| 精良机缘 | 25%  | 法宝碎片、功德、劫气选择         |
| 稀有机缘 | 4.5% | 跟脚变化、强力法器            |
| 天命机缘 | 0.5% | 极稀有，前 7 天只可通过保底或剧情触发 |

前 7 天不要让天命机缘影响数值平衡。
可以只做展示型或轻量奖励。

---

### 5. 机缘保底

为了防止玩家几天都没有惊喜：

```text
每日首次收菜必触发 1 次普通或精良机缘。
连续 2 天未触发稀有机缘，第 3 天首次机缘必定升级为稀有。
首个本命法宝相关机缘为剧情保底。
首个跟脚提升机缘在第 3 ~ 第 5 天之间保底出现。
```

## 十五、破劫规则

### 1. 小境界不破劫

小境界提升只消耗道行。

例如：

```text
炼气士三重 → 炼气士四重
消耗道行
直接提升
```

### 2. 大境界需要破劫

每个大境界突破需要破劫。

前 7 天涉及两次破劫：

炼气士十重 → 真人一重
真人十重 → 地仙一重

---

## 十六、破劫成功率公式

第一版公式建议：

```text
破劫成功率 =
基础成功率
+ 功德加成
+ 跟脚加成
+ 护身法宝加成
+ 临时机缘加成
- 劫气压力
```

### 炼气士 → 真人

基础成功率：

```text
75%
```

新手保护：

首次破劫最低成功率不低于 95%。

也就是说，即使玩家功德不够，第一次破劫也基本成功。

这是首日爽感，不要卡玩家。

---

### 真人 → 地仙

基础成功率：

```text
60%
```

玩家通过以下方式提高：

功德
护身法宝
清心玉佩
玄黄护符
破劫机缘
跟脚提升

目标是让普通玩家第 7 天达到：

```text
破劫成功率 80% ~ 95%
```

---

## 十七、功德与劫气对破劫的影响

### 功德加成

建议前 7 天：

```text
每 100 功德 = 破劫成功率 +0.5%
最高加成 +20%
```

### 劫气压力

建议前 7 天：

```text
每 100 劫气 = 破劫成功率 -0.3%
最多降低 -15%
```

### 劫气收益

劫气同时提供：

```text
每 100 劫气 = 游历收益 +1%
每 100 劫气 = 法器 / 法宝碎片掉落 +0.5%
```

劫气要让玩家觉得很爽，但不能让玩家崩盘。

---

## 十八、破劫失败补偿

放置游戏里，破劫失败不能重罚。

破劫失败规则：

道行不清零。
最多扣除少量破劫材料。
给予失败成长补偿。
下次成功率提高。

失败文案：

```text
破劫失败。

你被杀劫反噬，心神震荡。
但这一劫并未毁去你的道行，反而让你窥见破劫之法。

获得：
劫火淬体
下次破劫成功率 +10%
法力 +5%
```

如果玩家连续失败：

```text
连续失败 2 次后，下次破劫必定成功。
```

前期必须保证玩家不会被破劫劝退。

## 十九、战斗结算设计

前 7 天不做复杂自动战斗。

战斗只做结算表现。

玩家选择地图后，系统自动产出：

道行
法力
法器碎片
术法残页
功德 / 劫气
机缘概率

### 地图结算公式

```text
地图收益 =
地图基础收益 × 主角战力压制倍率 × 法宝倍率 × 劫气倍率
```

### 战力压制

| 战力关系             | 结算效果        |
| ---------------- | ----------- |
| 玩家战力 < 推荐战力 80%  | 低效游历        |
| 玩家战力 80% ~ 100%  | 正常游历        |
| 玩家战力 100% ~ 150% | 收益 +10%     |
| 玩家战力 150% 以上     | 收益 +25%，可扫荡 |

### 小 Boss 挑战

小 Boss 不需要复杂操作。

只显示：

推荐战力
玩家战力
胜率
结算结果

示例：

```text
挑战：山野妖首

推荐战力：8000
你的战力：12000
胜率：100%

战斗结算：
你以雷纹木剑引落一道雷光，将妖首镇杀。

获得：
道行 +80 年
法器碎片 ×6
术法残页 ×4
功德 +100
```

## 二十六、最终核心体验总结

前 7 天的游戏体验必须非常清楚：

```text
我闭关。
我收菜。
我涨道行。
我升境界。
我遇机缘。
我选功德或劫气。
我获得本命法宝。
我破劫成真人。
我继续收菜。
我强化法宝。
我冲到地仙。
```

玩家前 7 天的情绪曲线应该是：

```text
第一天：我修起来了。
第二天：我的法宝好强。
第三天：我可以选择稳或猛。
第四天：我的战力能打 Boss 了。
第五天：我要准备破地仙劫。
第六天：马上成仙。
第七天：我成地仙了，下一步想看真仙神通。
```

一句话定义本阶段：

**用最少系统，让玩家在 7 天内完整体验一次“闭关收菜 → 境界暴涨 → 机缘改命 → 法宝爆发 → 破劫成仙”的主角成长爽感。**
