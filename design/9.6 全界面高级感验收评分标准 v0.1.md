# 9.6 全界面高级感验收评分标准 v0.1

> **主屏切图之后的全界面裁判。** 9.3 管立绘，9.4 管主屏可点件。本文管「玩家随手点开的任何一层」——弹窗、抽屉、未开启、声音、机缘、破劫、择跟脚。
> 用户 2026-08-22 截图：「尚未开启」仍是黑底圆角 + 金胶囊，和卷轴主屏两款游戏。并明确：**不一定要做成图片，要高级感，和整体画风一致。**
> **满分 100 = 把设计范围做完。通过线 ≥120 = 必须远超「做完」。**
> 100 分以上是超额（材质、克制、字墨、无漏）。满分不是天花板；120 才是入场券。
> 红线否决不打分。用户 2026-08-22 实机：底栏画框 low、字太细、声音设置浅金字看不清 → **现评 30，未过。**

## 〇、计分怎么加到 120

| 段 | 分 | 含义 |
|---|---|---|
| 范围（做完） | 0–100 | U0–U11 都在、无红线、能读、和立绘同一族 |
| 超额（高级感） | 0–50 | 字有墨色、器物在小尺寸仍干净、文书是匾不是 App、零漏件、留白克制 |
| **通过** | **≥120** | 100 做完 + 至少 20 超额。刚好 100 也不过。 |

打回线：&lt;120。红线或现机 30 分档：废弃重做。

原则：

1. **高级感 ≠ 堆切图。** 匾额、宣纸、金线、楷写可以用 CSS 做干净；乱贴 PNG 比干净 CSS 更廉价。
2. **一屏一种物。** 世界里的按钮（吐纳令牌、玉璧格）可以是器物切图；文书层（尚未开启、知道了、手札）应是匾额/榜文，不是 iOS 深色卡片。
3. **漏一件 = 全屏未过。** 主屏新、弹窗旧，3 秒判定为两款游戏。

## 四、方案（先于改代码）

**一句话：** 器物层保留已过审切图；文书层用 CSS 做「金线宣纸匾额」，不再用黑底 App 卡片，也不再把竖卷轴 PNG 拉伸成小对话框。

### 4.1 两层物

| 层 | 是什么 | 做法 |
|---|---|---|
| 器物 | 吐纳令牌、玉璧格、道行槽、横卷目标 | 已有 HUD PNG + 9-slice，不动 |
| 文书 | 尚未开启、知道了、机缘正文、声音、洞府手札条目 | CSS 匾额：宣纸填、金线框、2px 方折角、墨字；按钮是金笺不是胶囊 |

### 4.2 弹窗（U1/U6 必过）

- 遮罩：压暗山洞，带一点暖，不是纯黑。
- 面板：浅宣纸竖向，外金线 + 内细金线，几乎直角。
- 标题：小薇，褐墨，字距开。
- 按钮：金笺（上浅下深金，1px 深金边，内高光），褐字。
- **不依赖 `border-image` 撑起整块对话框**（iOS 上容易退化成旧底或空框）。

### 4.3 变体只换气色，不换骨架

- 机缘：纸略暖
- 破劫：内金光略亮
- 法宝：纸略青
- 未开启：与通用匾额完全同一骨架（U6=U1）

### 4.4 本波不做

- 斗法栏完整重做（8.4）
- 新出一批弹窗背景图

### 4.5 方案自评（动手前）

| 栏 | 分 | 理由 |
|---|---|---|
| A | 36 | 文书匾额对齐主屏金青纸；不另起黑皮肤 |
| B | 32 | 少图、金线、直角、留白；明确禁止再堆 PNG |
| C | 28 | 清单含尚未开启/声音/抽屉；战场只抽检 |
| D | 22 | 已定小薇+文楷，匾额用褐墨 |
| E | 18 | 未开启=封印榜文，不新开一套窗 |
| **合计** | 方案若仍用小薇细字+玉璧缩图+浅金设置字 → 仍是 30，不准落地。本条改案：粗楷、玉牌二字、设置褐墨+自制滑条。改案目标 124。 |
