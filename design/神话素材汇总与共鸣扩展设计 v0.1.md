## 〇、当前设定锚点（务必遵守）

- **三层正交，互不映射**：
  - 体系层 = 体/器/魂/劫（build 选择，**体系间无克**）
  - 五行层 = 木/火/土/金/水（**有生克**，驱动相邻 slot 共鸣）
  - 特质层 = 毒/混元/阴阳等（nullable trait tag，暂无机械效果，随规则按需启用）
- **共鸣引擎 = 纯基础设施**（存储 + 触发）；**共鸣规则 = 独立设计、按需注册、慢慢丰富**。
  - 现状：`web/js/resonance-system.js` 已实现 `registerChannel({id,name,enabled,condition,evaluate})`，通道倍率相乘。
  - 已注册通道：`wuxing`（enabled，克×1.0/生×1.6/基础×1.3）、`set`（enabled:false 留口子）。
- **方案 B**：每个斗法栏 slot 绑定一件法宝，法宝的 `wuxing` = 该 slot 共鸣的 leftWuxing。
- 器 = 法宝（treasure_table），**器本身无招式**，五行只是器的属性之一。御剑术/御器术 = 法术（保留为 slot 技能，非器）。
- 数值/归属一律记代办，**不轻易确定**；本文所有五行归属标 🔴待设计。

## 六、五行之外的共鸣通道构想（brainstorm）

> 引擎已支持多通道注册（倍率相乘）。以下每条 = 一个独立 `registerChannel` 候选，**按需启用、慢慢丰富**。
> 组合规则当前 = 相乘（初版，⚪待决策，第二条通道上线时定稿）。

### 通道 1：套装共鸣（Set）—— 已留口子 `set` channel
集齐同套法宝 ≥N 件触发。天然套装：
- **哪吒八件**：乾坤圈+混天绫+风火轮+火尖枪+金砖+九龙神火罩+阴阳剑+火枣（最少三件套起步）
- **诛仙四剑**：诛仙+戮仙+陷仙+绝仙（+诛仙阵图）
- **五方旗**：杏黄旗+离地焰光旗+青莲宝色旗+素色云界旗+真武皂雕旗（= 五行旗阵）
- **封神三件**：封神榜+打神鞭+杏黄旗（姜子牙）
- **老君炼丹套**：八卦炉+紫金红葫芦+羊脂玉净瓶+幌金绳+七星剑+芭蕉扇+金刚琢
- **三霄套**：金蛟剪+混元金斗+飞剑
- **魔家四将**：青云剑+混元伞+琵琶+花狐貂
- 数据需求：treasure_table 加 `set_id` + `set_name`；trigger = equipped slots 含同 set ≥N。

### 通道 2：神兽共鸣（Divine Beast）—— 山海经素材
法宝/坐骑带神兽 tag，集齐同组触发：
- **四灵**：青龙(木)+朱雀(火)+白虎(金)+玄武(水)（+黄龙/麒麟 土 补全五行）
- **四凶**：混沌+穷奇+梼杌+饕餮（凶煞/debuff 向）
- **龙生九子**：赑屃…囚牛（九子套，可分段触发）
- 数据需求：新增神兽实体表 或 treasure 加 `beast_tag`。

### 通道 3：师承 / 阵营共鸣（Lineage）—— 封神阵营
同阵营法宝 ≥N 触发，构筑路线（走阐教线 or 截教线）：
- **阐教**（元始系）：广成子/赤精子/太乙真人/文殊/普贤/慈航/惧留孙/玉鼎 等十二金仙法宝
- **截教**（通天系）：多宝/金灵/龟灵/无当/赵公明/三霄/吕岳/罗宣 法宝
- **西方教**（接引/准提）：七宝妙树/六根清净竹/青莲宝色旗
- **散仙**：陆压/云中子/燃灯
- 数据需求：treasure 加 `faction`（chan/jie/west/san）；companion_table 已有阵营锚点。

### 通道 4：因果 / 封神榜共鸣（Karma）—— 封神主题
- **打神鞭** 专打封神榜上有名之人 → 对"榜上有名"敌方（特定 boss origin）加成
- **封神图鉴**：击败 boss 后"封神"，收集 → 图鉴共鸣（meta 进度）
- 数据需求：boss/enemy 加 `on_fengshen_list` tag；打神鞭法宝 condition。

### 通道 5：阴阳共鸣（Yin-Yang）—— 二元轴
- 素材：阴阳镜、阴阳二气瓶、太极图、阴阳剑、两仪二圣（烛照/幽荧）
- 攻(阳)/补(阴) 搭配 → 阴阳调和 bonus
- 数据需求：treasure 加 `polarity`（yin/yang/null）；trigger = 同时装备阴+阳。
- 注意：阴阳是**分类轴**非环，不合"相邻 slot"模型，作整队 buff 更合适。

### 通道 6：品阶共鸣（Tier）
- 先天至宝/先天灵宝组合 → 先天共鸣
- 数据需求：treasure 加 `tier`（xiantian_zhibao/xiantian_lingbao/houtian/gongde）。

### 通道 7：化身 / 血脉共鸣（Incarnation）—— companion 绑定
- 哪吒（莲花化身）+ 哪吒法宝 → 化身共鸣；杨戬（八九玄功）+ 三尖两刃刀+哮天犬；孙悟空 + 金箍棒
- 数据需求：companion 加 `signature_treasures[]`；trigger = companion 上阵 + 其专属法宝装备。
- 优势：companion_table 19 人已就绪，挂 tag 即可。

### 通道 8：主仆 / 传承共鸣（Ownership）
- 法宝流转史：定海珠（赵公明→燃灯）、紫金铃（老君→观音→金毛犼）
- 数据需求：treasure 加 `origin_owner`；trigger = 原主 companion + 法宝。

### 通道优先级建议🔴
1. **套装（1）** —— 引擎已留口子，数据成本最低（加 set_id），最先做
2. **化身（7）** —— companion 已就绪，挂 signature_treasures 即可，主题强
3. **师承（3）** —— 构筑深度大，阵营路线 = 玩法分支
4. **神兽（2）/ 阴阳（5）/ 品阶（6）/ 因果（4）/ 传承（8）** —— 视素材丰富度逐步加
