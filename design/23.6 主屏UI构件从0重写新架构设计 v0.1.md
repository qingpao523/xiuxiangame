# 23.6 主屏 UI 构件从 0 重写 · 新架构设计 v0.1

> 用户第四次拍板（原话）："主屏 UI 构件全部从0开始重写！！！！！！放弃原来的旧架构！！！！"
> 前三次都是在旧骨架上盖皮/打补丁，本次**彻底放弃旧架构，从 0 重写**。

## 一、旧架构的问题（为什么必须抛弃）
- index.html #app 是旧框架的盒子堆叠（top-banner/resource-strip/stage/goal-panel/progress-zone/status-line/main-btn/auto-row/bottom-nav 一列摞下来）。
- style.css 4384 行旧规则 + style-hud-v3.css 盖皮 = 三层叠加，改一处牵三处，永远在"修旧"不是"建新"。
- 地图图文不符、点击热区错位等根子问题，都是旧架构的数据-视图耦合方式造成的，补丁修不好。

## 二、从 0 重写的新架构原则
1. **全新 DOM 骨架**：index.html #app 重写为按 v3 设计元素组织的语义化结构，不再是旧盒子堆叠。
2. **全新样式表**：新建 web/style-main-v3.css 作为主屏唯一权威样式，**从 0 写**，不继承/不 override 旧 style.css 的主屏规则。旧 style.css 的主屏段作废（保留面板/弹窗/斗法/卷首等非主屏段）。
3. **保留 JS 钩子**：ui.js 引用的 46 个 DOM ID 全部保留（ID 是 JS 契约），但 DOM 的**组织结构/层级/容器**全新设计。
4. **以生成的 v3 素材为基准**：匾额/玉璧/目标卡/道行槽/主按钮/导航牌/云台，按素材天然比例构图，文字落预留空地。
