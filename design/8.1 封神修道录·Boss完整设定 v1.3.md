# 8.1 封神修道录 · Boss 完整设定（终稿 v1.3）

> 来源：用户口述终稿（2026-08-21），战斗系统 8.0 的配套 Boss 设计。
> 战斗系统：斗法栏（3-4 术法槽位自动释放），无命中/闪避判定，无手动选目标。
> 本批次为「先写入游戏内」的第一批 Boss（炼气→真人阶段）；地仙阶段 Boss（如闻仲首战，雷系）为后续批次。
> 系属映射：体=body / 雷=thunder / 火=fire / 器=weapon / 魂=soul / 劫=calamity。

## Boss 1：张桂芳

| 字段 | 内容 |
|------|------|
| 所在阶段 | 炼气·四重 |
| 主系 | 魂 |
| 实力档 | 真仙 |
| 核心机制 | "呼名落马"——每隔3回合强制打断玩家一个术法槽，重置该槽位冷却 |
| 攻击模式 | 常规回合：枪击（物理低伤）。每3回合：施展"呼名术"→随机选玩家一个术法槽强制中断+冷却重置。血量<30%时频率变为每2回合 |
| 破解方式 | ①配置多个短CD术法（被打断损失小）；②配一个高CD大招+多个低CD填充，打断大招仍有输出；③纯暴力高伤配置在3回合内秒掉 |
| 掉落 | 魂系精华×3 + "呼名残响"（魂系法宝制作材料） |
| 原著锚点 | 第40回，张桂芳呼名落马术大败周营，后被哪吒以莲花化身无魂魄破解 |
| 叙事触发 | "一声厉喝从远处传来，你脑中嗡鸣，刚凝聚的法力瞬间溃散——有人在叫你的道号。" |

## Boss 4-7：魔家四将（4连战）

## 实现注记（与现有引擎的差距，2026-08-21 调研）

- 数据：boss_table.json 现有 boss_001..boss_022；本批新增 boss_023..boss_031。unlock_condition 用 realm_id（炼气·N=rq_0N，真人·N=zr_0N）。
- 机制分发：battle-engine-v2.js 两个钩子 `_processMechanicTurnStart` / `_processMechanicEnemyPhase`，switch(battle.mechanic)，状态存 battle.mechanicState（turnCount 每玩家回合自增）。本批 9 个机制均为新 key，需在 switch 加 case + battle-ui-v2.js `_mechanicText` 加文案。
- **关键缺口：当前引擎无任何「术法冷却/CD」系统**（executePlayerRound 每回合全槽位释放，skill_table 无 CD 字段）。张桂芳（打断+CD重置）与魔礼海（三弦CD+1）依赖此系统，需先建 per-slot cooldown 子系统，否则只能近似。
- 减伤场（石矶-40%/魔礼红-25%/罗宣烟雾-30%）：需玩家侧「术法伤害减益」字段并在伤害计算消费（V2 现无此消费点，参考 V1 picture_world 死代码）。
- 连战（魔家四将）：用 cfg.phases（含 intro）+ phase_advance 事件，仿 startArrayBattle；场间回血50%/回满法力需在 phase 切换注入。
- 真实伤害（火灵引爆25%/罗宣焚城50%）：需绕过罡气/圣盾的伤害通道。
