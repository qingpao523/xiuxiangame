# 《封神修道录》游戏设定文档 v1.0

## 一、项目定位

### 游戏类型

主角成长型放置修仙游戏。

核心不是门派经营，不是宗门管理，也不是弟子养成，而是玩家扮演一个主角，从无名炼气士开始，在封神大劫中不断闭关、修道、突破、悟神通、炼法宝、得机缘，最终成长为不入封神榜、不受天庭束缚的逍遥大能。

### 核心卖点

本游戏提取封神题材中最适合放置修仙的元素：

封神大劫
阐截斗法
法宝争锋
神通修炼
跟脚蜕变
机缘奇遇
天庭神位
封神榜压制
肉身成圣
混元逍遥

这些元素全部服务于一个目标：

**让玩家这个主角不断变强。**

玩家不是管理一个宗门，而是修炼一个人。

---

## 二、一句话概念

玩家扮演一名封神大劫边缘的无名炼气士，通过闭关积累道行、突破九大境界、提升跟脚、修炼神通、祭炼法宝、获得机缘，在封神乱世中一路成长，最终跳出封神榜，证得混元逍遥。

---

## 三、游戏核心爽感

本游戏的爽感来自五件事：

### 1. 挂机涨道行

玩家离线后，主角自动闭关修炼。
上线后直接领取大量道行、法力、功德、法宝碎片、神通残页。

玩家感受：

“我没操作，但我变强了。”

---

### 2. 道行升境界

道行是主经验。
道行满了，主角就可以突破境界。

玩家感受：

“我闭关越久，境界越高。”

---

### 3. 境界开上限

每次突破大境界，都解锁新的系统能力。

例如：

炼气士解锁基础法术。
真人解锁本命法宝。
地仙解锁法宝祭炼。
天仙进入封神战场。
真仙解锁神通进阶。
金仙开启封神榜挑战。
太乙掌握大道神通。
大罗开始反制因果。
混元最终跳出封神榜。

玩家感受：

“每次突破，都像换了一个层级。”

---

### 4. 法宝带来战力暴涨

封神世界里，法宝是最直观的爽点。
玩家获得法宝后，战力不能只是小幅增加，而应该立刻产生巨大变化。

例如：

获得番天印仿品，战力暴涨，解锁镇压技能。
获得九龙神火罩残片，挂机刷怪效率提升。
获得混天绫残影，获得免死能力。
获得金蛟剪残影，低血敌人直接斩杀。

玩家感受：

“我拿到宝物，立刻变强。”

---

### 5. 机缘制造惊喜

玩家每天上线不能只是固定收益。
必须有随机奇遇。

比如：

闭关梦入紫霄。
战场拾得法宝残片。
雷骨入体改变跟脚。
古碑悟出神通。
杀劫临身，选择功德化解或劫气入体。

玩家感受：

“每次上线都有可能撞大运。”

---

## 四、世界背景

天地杀劫已起，商周气运更替，天庭神位空缺，封神榜悬于三界之上。

阐教顺天应命，辅佐西岐。
截教万仙来朝，门人卷入大劫。
人间兵火连年，妖魔趁乱而起。
天庭欲补全神位，诸仙真灵皆有上榜之危。
大劫之中，有人成神，有人身死，有人道毁，有人借劫而起。

玩家并非大教亲传，也不是榜上有名之人。

玩家只是山野之间一个无名炼气士，原本只想闭关修道，远离红尘杀劫。可封神大劫席卷三界，天地之间处处都是危险，也处处都是机缘。

别人入劫，是身死上榜。
玩家入劫，是捡取机缘。
别人争天命，玩家涨道行。
别人受封神位，玩家炼化榜文。
别人被封神榜束缚，玩家最终跳出榜外，自成大道。

---

## 五、玩家身份

玩家身份为：

**封神大劫边缘的无名炼气士。**

初始设定：

出身普通。
根脚低微。
没有大教靠山。
没有天生法宝。
没有封神榜正位。
只有一门残缺修道法和一座破旧洞府。

但玩家最大的优势是：

**不在封神大劫核心名单之中。**

这意味着玩家没有天命加身，也没有必死因果。
他可以在大劫边缘修炼、游历、捡漏、突破、炼宝、悟法，最终从一个无名小修成长为三界之外的逍遥者。

---

## 六、主境界体系

本游戏不采用“元婴、化神、炼虚”这套凡人流境界。

游戏采用更符合封神味、同时玩家一眼能懂的九大境界：

```text
炼气士
真人
地仙
天仙
真仙
金仙
太乙
大罗
混元
```

每个大境界分为十重。

例如：

```text
炼气士一重 ~ 炼气士十重
真人一重 ~ 真人十重
地仙一重 ~ 地仙十重
天仙一重 ~ 天仙十重
真仙一重 ~ 真仙十重
金仙一重 ~ 金仙十重
太乙一重 ~ 太乙十重
大罗一重 ~ 大罗十重
混元一重 ~ 混元十重
```

小境界提供持续成长。
大境界提供重大突破。
每十重突破一次大境界，触发动画、文案、战力暴涨和系统解锁。

# 七、九大境界详细设定

## 1. 炼气士

### 世界观解释

初窥大道，会法术，会御器。

炼气士是最基础的修道者，仍未完全脱离凡俗，但已经能够吐纳灵气、驱使符箓、御使小型法器。

### 玩家体验

升级快。
突破频繁。
很快获得基础法术。
从普通凡人变成能斩妖的小修士。

### 解锁内容

闭关
道行系统
基础法术
基础游历
山野妖患地图

### 战斗表现

符火
小雷法
御器飞击
护身符

---

## 2. 真人

### 世界观解释

炼成道体，可斩妖除魔。

真人已经不再是普通炼气士，而是真正踏入大道之门。道体初成，法力稳定，能够正面斩妖除魔。

### 玩家体验

第一次明显变强。
解锁本命法宝。
自动战斗效率提升。
主角开始有真正修仙感。

### 解锁内容

护体道光
本命法宝
自动施法
陈塘关外围地图

### 战斗表现

御剑斩妖
小范围群攻
法术自动循环
基础护体道光

---

## 3. 地仙

### 世界观解释

脱离凡俗，寿元大增。

地仙已经具备仙人雏形，虽未登天，却已不再受普通凡人寿数束缚。能够感应地脉，借山川灵气修炼。

### 玩家体验

开始有仙人味。
挂机收益提升。
法宝祭炼开启。
战斗续航增强。

### 解锁内容

地脉感应
法宝祭炼
挂机收益提升
骷髅山边界地图

### 战斗表现

借地脉恢复法力。
踏地起阵。
持续战斗能力增强。

## 4. 天仙

道行大成，可腾云入天。

天仙开始真正进入仙道层级，能够腾云驾雾，俯瞰人间兵火，也开始接触封神战场的真正边缘。

### 玩家体验

解锁第二法宝槽。

玩家第一次感觉自己进入“大世界”。

### 解锁内容

腾云驾雾
第二法宝槽

西岐战场地图

### 战斗表现

真仙阶段，主角的精、气、神开始凝聚，三花初现。法术不再只是普通法术，而开始进阶为真正神通。

# 八、五大核心成长系统

本游戏的主角成长由五大系统构成：

```text
修道 / 道行
跟脚
神通
法宝
机缘
```

这五个系统不是平行堆叠，而是互相咬合：

```text
修道涨道行
道行升境界
境界开上限
跟脚给倍率
神通定打法
法宝给爆点
机缘造惊喜
```

---

## 九、修道 / 道行系统

### 系统定位

道行是本游戏的主经验。

玩家不获得“经验值”，而是获得“道行”。

道行来自：

闭关
游历
斩妖
封神战场
挑战残影
机缘奇遇
炼化榜文
破除杀劫

### 道行表现

道行使用“年”为单位，更有封神修道味。

例如：

```text
闭关结束。

你参玄悟道三百年。

获得：
道行 +300 年
法力 +12.5 万
功德 +8000
劫气 +3200
法宝碎片 ×16
神通残页 ×5

当前境界：
真人七重 → 真人九重
```

### 道行作用

道行满了，主角就可以提升小境界。

例如：

```text
当前境界：真人九重
所需道行：920 / 1000 年
```

达到要求后：

```text
真人九重 → 真人十重
```

每十重后进入大突破。

例如：

```text
真人十重 → 地仙一重
```

### 道行爽感

道行是最稳定的放置收益。
玩家每次上线，都应该看到道行大幅增长。

核心感受：

**闭关越久，道行越深。
道行越深，境界越高。
境界越高，主角越强。**

---

## 十、跟脚系统

### 系统定位

跟脚是主角的天赋底盘。

封神世界非常讲跟脚。
同样的修道时间，普通凡骨和先天道体的成长完全不同。

所以跟脚决定的是：

道行收益倍率
突破成功率
神通上限
法宝适配度
特殊流派加成

### 跟脚等级

基础跟脚可以分为：

```text
凡骨
灵根
仙骨
道体
先天根脚
混元根脚
```

玩家初始为：

```text
凡骨炼气士
```

通过机缘、突破、法宝洗炼、功德淬体，可以提升或改变跟脚。

### 跟脚示例

| 跟脚   | 效果                    |
| ---- | --------------------- |
| 凡骨   | 无特殊加成                 |
| 灵根   | 道行收益 +20%             |
| 仙骨   | 突破成功率 +10%，法力 +30%    |
| 风雷道体 | 雷法伤害 +50%，雷系法宝威力 +30% |
| 火德道体 | 火法持续伤害 +60%，炼化收益 +20% |
| 功德金身 | 杀劫抗性 +30%，突破更稳        |
| 劫气道体 | 攻击 +80%，但破劫压力增加       |
| 先天道体 | 道行收益 +100%，神通上限 +1    |
| 混元根脚 | 所有成长倍率提升，终局突破条件降低     |

### 跟脚变化示例

```text
机缘：雷骨入体

你在西岐战场拾得一枚雷部神骨，炼化后肉身生出风雷之纹。

跟脚变化：
仙骨 → 风雷道体

雷法伤害 +50%
雷系法宝威力 +30%
雷法神通突破上限 +1
```

### 跟脚爽感

跟脚不是复杂养成，而是让玩家感受到：

**我这个主角的底子越来越强。**

## 十一、神通系统

### 系统定位

神通是主角的技能流派。

放置游戏不适合堆几十个技能，所以神通应该走少而精的流派路线。

建议初版做五条流派：

```text
雷法
火法
剑诀
魂法
劫法
```

---

### 定位

爆发、破邪、打断。

### 玩家爽感

开局爆发。
克制妖邪魂体。

### 成长路线

```text
↓

↓

↓

```

## 十二、法宝系统

### 系统定位

法宝是封神题材最大的战力爆点。

封神世界里，很多时候谁强，不只看道行，还看手里有没有法宝。

所以玩家获得法宝时，必须立刻有强烈反馈：

```text
获得法宝：番天印仿品

战力 +320%
解锁法宝技：翻天镇岳
效果：召唤巨印砸落，镇压全场敌人。
```

## 十三、机缘系统

### 系统定位

机缘是随机惊喜系统。

玩家不能每天上线只拿固定收益。
必须有随机事件，让玩家觉得每次上线都有机会撞大运。

机缘可以出现在：

闭关时
游历时
突破时
挑战封神榜时
炼化法宝时
破除杀劫时

---

## 机缘类型

机缘分为五类：

| 机缘类型      | 奖励           |
| --------- | ------------ |
| 道行机缘      | 直接增加大量道行     |
| 跟脚机缘      | 改变或提升主角资质    |
| 神通机缘      | 获得神通残页或技能进阶  |
| 法宝机缘      | 获得法宝碎片、残影、宝胚 |
| 功德 / 劫气机缘 | 改变成长路线       |

---

## 机缘示例

### 1. 道行机缘：梦入紫霄

```text
你闭关时梦见紫气东来，耳边似有大道之音。

```

## 机缘设计原则

机缘必须简单。
一个机缘最多两个选择。
奖励要直接。
文案要有封神味。
不能让玩家读半天还不知道发生了什么。

# 十四、功德与劫气

功德和劫气是封神大劫中的两种特殊资源。

## 功德

功德代表顺天、护生、化劫、救人所得。

作用：

提升突破稳定性。
降低杀劫压力。
强化护身类神通。
提高拒绝上榜概率。
适合稳健成长。

适合流派：

功德金身
雷法正道
护身法宝
稳定突破流

---

## 劫气

劫气代表战场、杀伐、因果、大劫之力。

作用：

提升攻击。
强化杀伐神通。
提高法宝爆发。
增加高收益机缘出现概率。
但会增加杀劫压力。

适合流派：

劫法爆发
剑诀斩杀
六魂幡影
高风险高收益流

---

## 功德与劫气的选择

玩家经常会遇到二选一：

```text
以功德化劫：更稳。
炼劫入体：更猛。
```

这就是封神背景下的主角成长分歧。

# 十五、破劫系统

大境界突破不叫“渡劫”，而叫“破劫”。

封神世界核心不是普通雷劫，而是杀劫、因果、封神榜压制。

每次大境界突破，需要破除一重劫数。

例如：

```text
突破：真仙十重 → 金仙一重

需要：
道行达到要求
功德足够
破劫成功率达到 70%
```

玩家点击突破后：

成功：

```text
破劫成功！

三花聚顶，五气朝元。
金仙道果初成。

境界：
真仙十重 → 金仙一重

战力 +800%
封神榜挑战开启
法宝威力 +100%
杀劫抗性 +20%
```

失败：

```text
破劫失败。

你被杀劫反噬，但道行未散。
获得：劫火淬体
下次破劫成功率 +10%
```

放置游戏里失败不能太伤。
失败也必须给成长。

封神榜不是宗门系统，也不是弟子系统。

玩家挑战榜上残影、神位试炼、封神战场记忆。

每击败一个残影，就获得：

道行
功德
劫气
法宝碎片
神通残页
榜文碎片
称号进度

示例：

```text

道行 +300 年

雷道感悟 +1200

```

封神榜的核心不是让玩家上榜，而是：

**玩家不断挑战榜上强者，最终跳出榜外。**

流派被动

# 二十四、终局路线

游戏最终不是普通飞升，而是三种封神结局。

## 1. 受封天庭

玩家接受天庭敕封，获得神位。

优势：

放置收益稳定。
香火持续增长。
获得天庭神通。
成长压力较低。

劣势：

受神位约束。
最终上限较低。
不完全逍遥。

适合轻松挂机玩家。

---

## 2. 肉身成圣

玩家不入封神榜，以自身道行强行渡过杀劫。

优势：

战力极高。
不受神位束缚。
主角成长爽感强。

劣势：

破劫难度更高。
需要更强法宝、功德和跟脚。

适合追求个人战力的玩家。

---

## 3. 混元逍遥

玩家不受天庭、不入神榜、不沾大教因果，以自身大道成就混元。

优势：

最终上限最高。
完全自由。
终局爽感最强。

劣势：

需要完成高要求成长条件：

混元根脚
大罗圆满
终极法宝
大道神通
足够功德
足够破劫能力

适合长期玩家。

# 二十六、最终项目定义

这款游戏不是宗门经营，也不是传统凡人流修仙。

它是一款：

**封神背景下的主角个人成长型放置修仙游戏。**

核心系统是：

```text
境界
道行
跟脚
神通
法宝
机缘
封神榜
破劫
```

核心循环是：

```text
挂机闭关
领取道行
突破境界
提升跟脚
修炼神通
祭炼法宝
触发机缘
挑战封神榜
破劫成道
```

核心爽感是：

```text
我上线就领奖。
我闭关就涨道行。
我突破就变强。
我得机缘就改命。
我炼法宝就战力暴涨。
我修神通就碾压战场。
我最终不入封神榜，自己成道。
```

一句话总结：

**一个无名炼气士，在封神大劫中靠闭关修道、法宝祭炼、神通进阶、跟脚蜕变和机缘奇遇，从炼气士一路成长到混元逍遥，最终跳出封神榜，成为三界之外的真正大能。**
