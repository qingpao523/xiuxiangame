# 15.1 地图渐进解锁体验与美术素材规划 v0.1

> 生成 2026-08-22。用户指令（2026-08-22）：「地图做得太垃圾了，地图我需要一层一层的打开，你现在纯摆东西，太垃圾了，你先把地图需要的新的风格美术素材规划出来，按照我们新的美术标准，考虑下怎么放进去更好。」
> 本文是**规划**（非实现）：诊断当前地图问题 → 设计「一层一层打开」的渐进解锁体验 → 按新美术标准（design/9.2）规划所需美术素材 → 给出整合方案与分批路线。
> 关联：design/15.0 玩法与地图容器（F1 四大部洲/F2 单地图探索/F3 境界+prev_map 双锁）；美术需求.md §12（现有静态地图美术 spec，本文**扩展**之，不重复）；design/9.2 美术风格统一（风格锁 v2）；design/9.3 美术素材验收。

## 〇、问题诊断：当前地图为什么「垃圾」

当前 `web/js/world-map.js`（封神山河图）的实现是**静态摆放**：

| 现状 | 问题 |
|---|---|
| 五大部洲 = `CONTINENT_META` 半透明色块（rect/circle，纯色 `#efdcbd` 等） | 没有真实美术，只是水彩占位色块 |
| 9 可玩节点 + 11 地标 = 按 `wx/wy` 百分比坐标摆放的 `button.world-map-node` | 纯坐标摆放（"纯摆东西"），节点之间没有旅程感 |
| 节点图标 = `_glyph` **文字字符**（榜/城/宫/岛/关/山/野/府/阵） | 没有图标美术，只是汉字 |
| 推进链 = `_buildSvg` 连线，reached 加 `lit` class | 只有"亮/不亮"两态，没有渐进展开 |
| 解锁 = F3 数据门（`unlock_realm`+`prev_map`，unlock-manager.js getAvailableMaps） | **门控只是数据**，视觉上所有节点一开始就全部摆在那里，没有"一层一层打开"的体验 |

**核心症结**：门控逻辑（F3）存在，但**视觉呈现是一次性全摆**——玩家打开地图，所有部洲、所有节点同时可见（只是 locked/reached 两态）。没有：
1. **渐进揭示**（fog of war 随境界逐层揭开）；
2. **真实美术**（Q 版地标插画，而非色块+文字）；
3. **旅程感**（一条你正在走的伐纣之路，而非散点）；
4. **解锁仪式感**（破境时新区域"打开"的动画）。

用户要的「一层一层打开」= 把 F3 的**数据门控**翻译成**视觉渐进体验**。

## 一、渐进解锁体验设计（"一层一层打开"）

### 1.1 层级模型：境界 = 层

把地图的"层"与玩家的**境界进度**绑定（复用 F3 的 `unlock_realm`，但视觉化）：

| 层 | 对应境界 | 打开的区域 | 体验 |
|---|---|---|---|
| 第 1 层 | 炼气（rq） | 南赡部洲·山野（map_001）+ 山野洞府（home） | 开局只见脚下山野，其余皆封 |
| 第 2 层 | 真人（zr） | 南赡部洲·陈塘关（map_002） | 破境→陈塘关封印揭开 |
| 第 3 层 | 地仙（dx） | 南赡部洲·骷髅山（map_003）+ 西岐（map_004） | 伐纣主线展开 |
| 第 4 层 | 天仙~真仙（tx/zx） | 十绝阵（map_005）+ 九曲黄河（map_006） | 截教大阵 |
| 第 5 层 | 金仙~太乙（jx/ty） | 万仙阵（map_007）+ 封神台（map_008） | 封神终局 |
| 第 6 层 | 大罗~混元（dl/zs/hy） | 混元道场（map_009）+ 跨部洲（东胜/西牛/北俱/须弥昆仑）开放 | 世界全开 |

> 部洲渐进：**南赡部洲**（伐纣主舞台）最先全开；**东胜神洲/西牛贺洲/北俱芦洲/须弥昆仑**作为高层级区域，前期以"封印远景"呈现（看得见轮廓、进不去），到对应境界才"解封"可探索。这正好对应 11 个 `FLAVOR_LANDMARKS`（朝歌/青丘/玉虚宫/灵山/金鳌岛/烛龙/精卫…）的升格节奏。

### 1.2 节点状态机（5 态，各有专属美术）

当前只有 `locked`/`reached`/`current` 三态。扩展为 **5 态**，每态视觉分明：

| 状态 | 含义 | 视觉 |
|---|---|---|
| `sealed`（封印） | 境界未到，区域整体封 | 灰暗剪影 + 封神榜封印纹（金色卷轴光符）覆盖 + 锁形 |
| `locked`（未达） | 区域已开但本节点前置未满足（prev_map 未通） | 半透明节点 + 虚线连接 + 暗 |
| `available`（可进） | 已解锁、可挑战 | 全彩节点图标 + 呼吸光晕 |
| `current`（当前） | 玩家所在/正在攻 | 高亮主角标记 + 强光晕 + 动效 |
| `completed`（已通） | 已击败 Boss | 节点加"✓"功德暖金圈 + 略降饱和（已成过往） |

### 1.3 封神榜封印 fog（主题化 fog of war）

不用通用战争迷雾，用**封神榜封印**作 fog（合 9.2 §2.3 三符号色：榜文=金色卷轴光）：
- 未开区域覆盖一层**金色卷轴封印纹 fog**（半透明，隐约可见区域轮廓但细节封住）。
- 破境时 fog **揭开动画**：封印纹碎裂/卷起 → 区域色彩涌入 → 节点浮现。
- fog 与 `seal-pressure`（榜文感应）视觉统一：封印越强的区域，fog 金光越盛。

### 1.4 解锁仪式（reveal 动画）

破境到新境界时（`Atmosphere.playBreakthrough` 已有破劫演出），地图给一段 **reveal 演出**：
1. 镜头聚焦新区域；
2. 封印 fog 碎裂揭开（CSS/JS 动画，~1.5s）；
3. 区域底图从灰暗→全彩（colorize transition）；
4. 新节点从雾中浮现 + 命名弹幕（"陈塘关 · 解封"）；
5. 伐纣路径向前延伸一段（路径动画）。

### 1.5 伐纣旅程路径（journey，非散点）

把 `_buildSvg` 的静态连线升级为**旅程路径**：
- 南赡部洲的 `prev_map` 链（山野→陈塘→骷髅山→西岐→…）渲染为一条**可见的伐纣古道**（Q 版路径素材，非细线）。
- 路径随进度**逐段点亮/延伸**：已通段为实体古道（暖色），未通段为虚线/雾中若隐若现。
- 玩家进度在路径上有一个**行进标记**（主角小像/云气），强化"我在走这条路"的旅程感。

## 三、整合方案（怎么放进去更好）

### 3.1 渲染层改造（web/js/world-map.js）

| 现状 | 改造 |
|---|---|
| `CONTINENT_META` 纯色块（`_buildSvg` rect/circle） | 替换为**部洲底图** `<img>`/背景层（5 张拼合），保留 wx/wy 坐标作节点定位锚 |
| `_glyph` 文字字符 | 替换为**节点图标** `<img src="assets/map/node_{icon_kind}_{map_id}.png">`（MAP_NODE_ICONS 映射） |
| 无 fog | 加 **封印 fog 覆盖层**：sealed 区域叠封印纹 img + CSS mask；按节点状态机渲染 |
| 连线 lit/unlit 两态 | 升级为**伐纣古道路径**：已通实体段/未通虚线段 + 行进标记 |
| 一次性全摆 | **渐进渲染**：只全彩渲染 active+completed 区域；sealed 区域 fog 覆盖；locked 半透明 |
| 无解锁动画 | 破境触发 **reveal 演出**（1.4）：fog 碎裂→colorize→节点浮现→路径延伸 |

### 3.2 状态判定（复用 F3，视觉化）

`_nodeReached`/`_buildNode` 扩展为 5 态判定（1.2）：
- `sealed`：节点所在部洲境界未到（`UnlockManager.conditionMet(state, continent_unlock_realm)` false）。
- `locked`：部洲已开但 `prev_map` 未通。
- `available`/`current`/`completed`：按 `boss_clears`/`current_map_id` 判定。

### 3.3 资产加载

- 目录：`web/assets/map/`（continents/ 部洲底图、nodes/ 节点图标、landmarks/ 地标剪影、fog/ 封印纹、path/ 路径、fx/ reveal 动效）。
- **懒加载**：部洲底图按揭示进度加载（已开区域才加载高清图），未开区域用低清/剪影占位（省流量，合手游体验）。
- 占位兼容：素材未到位时，`MAP_NODE_ICONS`/底图缺失则回退当前色块+glyph（不阻塞，渐进替换）。

### 3.4 原子性（合 9.2 §4 铁律）

按 9.2「一屏涉及素材必须同波全换」：**大地图屏**作为一个原子——部洲底图+节点图标+fog+路径+reveal 必须**同波到位**才上线该屏新美术；宁可整屏晚上，不许半屏混用（半色块半插画=廉价拼凑）。

## 五、分批路线与验收

### 5.1 分批（按玩家曝光顺序，合 9.2 §4）

| 波 | 内容 | 优先 |
|---|---|---|
| **MVP（第 1 波）** | 南赡部洲底图 + 9 节点图标 + 封印 fog + 5 态状态机 + reveal 动画 + 伐纣古道路径 | 最高（前 30 分钟可见，合 9.2 P0） |
| 第 2 波 | 须弥昆仑中枢底图 + 11 地标剪影 + 行进标记 + 路径动效 | 中 |
| 第 3 波 | 东胜/西牛/北俱三部洲底图（高层级区域解封）+ 单地图背景 9 张 + 探索点图标 | 后续 |

### 5.2 验收（引 design/9.3）

- **渐进体验**：新玩家开局只见南赡部洲山野（第 1 层），其余封印；破境触发 reveal 动画逐层打开；节点 5 态视觉分明。
- **美术合规**：所有素材过 9.2 风格锁 v2 + 负面清单 + 主题锁（每张含封神锚点）；9.3 评分达标。
- **原子性**：大地图屏整屏同波换，无半屏混用。
- **性能**：懒加载，未开区域低清占位；移动端流畅。
- **兼容**：素材缺失回退色块+glyph，不阻塞。
