# 10.0 封神修道录 · 手游内容总规划 v0.2（详细可执行版）

> 生成 2026-08-21。本文是对 design/ 全部 35 份文档的一次总遍历与整合，回答一个问题：**把这款游戏真正做出来，到底要填多少东西、按什么顺序填。**
> 本文不替代既有文档，而是做"总调度"：盘点现状 → 收敛冲突 → 摊开清单 → 排出批次。深度细节仍指向各专项文档。
> 用户背景：未做过游戏开发，需要把"道具/数值/每境界属性/每境界活动/动画/美术/音效"一项不漏地摊开。
> 权威方向：design/9.1（2026-08-20 与设计师会议纪要，用户确认真实）为最新决策口径。

## 〇、读前须知：这款游戏到底要做多少东西

一款手游的内容可拆成 **8 个域**。先看总量级，再看后文逐项摊开：

| 域 | 含义 | 本项目的量级（设计目标） | 当前完成度 |
|---|---|---|---|
| 1 角色与成长 | 境界/属性/流派/种族/跟脚 | 100 境界节点 + 4 流派 + 9 种族 + 6 跟脚 | 境界表已建(属性 sparse)，流派/种族机制未实现 |
| 2 数值与经济 | 战力曲线/产出/概率/平衡 | 指数战力曲线 + 双循环经济 + 破劫/掉落概率 | 曲线已有，平衡锚点散落各文档未统一 |
| 3 道具与装备 | 术法/神通/法宝/丹药/符箓/材料 | 术法25 + 神通8 + 法宝30+ + 丹12 + 符3 + 材料若干 | 术法23/法宝33已建，丹6/符0/材料sparse |
| 4 玩法与活动 | 战斗/Boss/遭遇/机缘/探索/势力/生活技艺/塔 | 6层Boss30+ / 机缘100+ / 探索点12+ / 4势力系统 / 3技艺 / 镇魔塔 | 战斗V2已做，Boss机制未接线，多数活动仅验收标准 |
| 5 叙事与文案 | 主线卷章/同伴弧/事件/手札/封神锚点 | 7-8 卷主线 + 20同伴弧 + 100事件 + 网状因果线 | 事件98/同伴19已建，无主线脊梁，网状叙事未实现 |
| 6 美术 | 立绘/图标/地图/UI/特效 | Q版立绘(主角/20同伴/31Boss) + 图标60+ + 地图9 + UI套件 | 接近 0（仅占位 icon_key 字段） |
| 7 动画 | 战斗动效/突破演出/手感动效 | 战斗CSS动效 + 破劫强演出 + 炼丹画符手感 | 战斗CSS已有，破劫演出弱，Q版动画规格空白 |
| 8 音效 | BGM/SFX | BGM若干 + SFX一套 | **完全为 0**（35 份文档零提及） |

**结论**：骨架（放置主循环 + 战斗V2 + 100境界 + 基础数据表）已通；**血肉（内容纵深）、表现（美术/动画/音效）、主线（剧情脊梁）三大块基本未动**。这是"缺多少"的真实答案。

## 七、美术 / 动画 / 音效资产总清单（你问的"是不是需要动画"）

### 7.1 直接回答：哪些要动画，哪些不要

| 场景 | 需要动画吗 | 说明 |
|---|---|---|
| **常规战斗** | **不需要帧动画** | design/8.0 明确"卡牌文字+日志+意图图标足够"。已有 CSS 动效（血条 transition/跳字/终极 overlay/blogIn 入场）。Q版战斗若要"法宝专属攻击动画"（9.1，如青椒变两条龙），用 **CSS/SVG/Lottie** 即可，**不急上 Spine/Godot** |
| **突破/破劫** | **需要强演出** | 1.x 要求金榜/劫气/金光/震屏。当前仅文字。这是动画投入重点（CSS 强动效或 Lottie） |
| **Q版立绘/小人** | 需要美术（非动画） | 9.1 转 Q版后，主角/同伴/Boss/法宝/地图全部需重出立绘 |
| **炼丹/画符/占卜** | 需要手感动效 | 6.3 要求操作反馈动效（CSS 即可） |
| **升重/结缘/受封** | 需要轻演出 | 清光/粒子/弹窗动效（CSS） |

**结论**：本项目是"文字修仙放置"，**战斗不依赖帧动画**，动画投入集中在**破劫强演出 + 各类轻反馈动效**，技术选型保持 **DOM/CSS/Lottie**，不引入游戏引擎。美术（Q版立绘）才是表现层大头。

## 八、数值与经济总纲

### 8.1 战力曲线

- 炼气 DPS 200-300 vs Boss HP 500-1000（3-5 轮击杀）
- 元婴级 DPS 5000-8000 vs HP 30000-60000
- 连锁：同系相邻 ×1.3；三连触发终极；本命法宝 ×1.5

- **修炼循环**：道行（升级货币）/ 法力（战斗+炼丹货币）—— 挂机产出，境界越高产出越高

- **8 资源**：spell_page/artifact_shard/treasure_shard/merit/refine_material/calamity/daoxing/mana

- 机缘：权重触发，双选项后果
