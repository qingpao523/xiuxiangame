## 一、封神演义地理（商周中原骨架）

**1. 东西对峙主轴**
- 商都朝歌在东（今河南淇县一带，存在「淇县说」争议）
- 周都西岐在西（今陕西宝鸡岐山县/周原遗址，跨岐山、扶风两县）
- 原著第21回「文王夸官逃五关」明确朝歌西行路线：**孟津 → 渡黄河 → 渑池 → 临潼关**

**2. 五关（自东向西的必经关隘带）**
```
朝歌 → 临潼关 → 潼关 → 穿云关 → 界牌关 → 汜水关 → 西岐
```
> 云中子命雷震子救姬昌「只许送出五关，不许同往西岐」（第21回），证五关为东西必经之路。

**3. 仙家两大总坛**
- 阐教总坛：昆仑山 **玉虚宫**（西，元始天尊）——对应《山海经·大荒西经》「西海之南、流沙之滨、赤水之后、黑水之前」之昆仑之丘（诠释性对应，原著未直接引）
- 截教总坛：**金鳌岛碧游宫**（东/东海，通天教主）——第72回「广成子三谒碧游宫」

## 三、辨伪：哪些是后世设定，非原著

1. **「四大部洲」（东胜神洲/西牛贺洲/南赡部洲/北俱芦洲）**：出自《西游记》第一回「感盘古开辟，三皇治世，五帝定伦，世界之间，遂分为四大部洲」；概念源出佛教「四大洲」（《长阿含经》《大楼炭经》）。**《封神演义》《山海经》均无「部洲」格局**。
2. **把西游记与封神视为同一宇宙、将四大部洲套封神**：属通俗科普的强行关联，不可采信。
3. **烛龙 ≠ 钟山之神烛阴**：两者是《大荒北经》（章尾山）与《海外北经》（钟山）的不同条目，常被混写为「钟山之烛龙」，需区分。
4. **朝歌「淇县说」**：主流参考坐标，但存在争议，非定论。
