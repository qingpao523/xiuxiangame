# 23.5 主屏 v3 重构 · 新构图设计 v0.1

> 用户拍板：按 v3 设计元素自己设计新构图，整体 ≥95 分（subagent 评）。本方案是**真重构**——重写 index.html #app DOM 骨架 + 配套 CSS，不再在旧骨架盖皮。

## 一、设计立意：青绿长卷 · 人是卷中小影

旧主屏是"盒子堆叠"（top-banner→资源→立绘→目标→道行→按钮→底栏，一格一格摞）。
新主屏是**一幅青绿长卷**：场景（#bg 青绿山水）是画卷本体，主角是卷中小影，HUD 元素是**浮在卷上的金玉构件**，不是摞起来的盒子。

## 二、新构图（移动端 414×896，四段式「天·人·事·路」）

### 天（顶部·轻）— 匾额 + 天象
- **匾额**（ui_title_plaque）居中浮于卷首，是长卷的题头。
- 卷/图/音 三枚小圆印贴匾额右侧。
- **榜文感应**（seal-pressure）压成匾额下一行细线，不抢戏。
- 资源**玉璧**（ui_res_disc ×N）：不再用大资源牌盒子，改成**一串玉璧直接浮在卷面上**（匾额与立绘之间），每璧 icon+数值，像长卷上的鉴藏印。

### 人（中心·主导）— 立绘 + 云台
- **主角立绘**（char-img）是绝对视觉中心，**放大到占屏高 ~42%**，立于**云台**（ui_cloud_stand）上。
- 场景青绿山水在立绘身后铺开（#bg）。
- 立绘区不留硬边框，让立绘直接"长"在卷面上。

### 事（下部·实）— 目标 + 道行 + 主按钮
- **目标卡**（ui_goal_card）：卷轴卡浮于立绘下方，承载当前目标+奖励。
- **道行槽**（ui_dao_trough）：紧贴目标卡，细长一道。
- **主按钮**（ui_main_btn）：唯一主行动，醒目居中，是"事"段的落点。
- 连续修行降级为按钮旁的小字链，不另立盒子。

### 路（底栏·稳）— 导航六玉牌
- **导航牌×6**（ui_nav_tile）：底栏六枚玉牌，锁定格灰阶+锁标。

## 三、与旧骨架的本质区别
| | 旧（盖皮） | 新（重构） |
|---|---|---|
| 资源 | 大资源牌盒子装玉璧 | 玉璧串直接浮卷面 |
| 立绘 | 小立绘塞在一格 | 立绘主导占屏 42% |
| 元素关系 | 盒子摞盒子 | 构件浮于长卷 |
| 视觉重心 | 散（每格平等） | 聚（立绘为心） |

## 四、实施
- 重写 index.html #app：保留 JS 钩子 ID（game-title/resource-strip/char-img/goal-text/progress-bar/main-btn/nav-btn 等），但重组容器结构与顺序。
- 重写 style-hud-v3.css 主屏段：按新构图布局（不再 override 旧骨架）。
- ui.js 渲染挂载点不变（ID 保留），仅 DOM 容器结构变。
- 重生黄金快照（DOM 变）。
