## 〇、定位与决策依据

### 〇.1 一句话定位
流派是玩家**中段一次性的 build 身份选择**：它不改变战斗引擎的 6 系连锁机制，而是在其上加一层"你能用什么、你擅长什么、你往哪个方向精深"的身份框架。对玩家是简单的四选一；对内容是组织术法/法宝/神通/事件的标签轴；对长线是"转世重选"带来的多周目驱动力。

### 〇.2 与既有系统的关系（实测锚点）
| 既有系统 | 实测位置 | 与流派的关系 |
|---|---|---|
| 6 系属（体/雷/火/器/魂/劫） | skill_table.spell_type（含体）、spell_table.spell_type（雷火器魂劫，**无体**） | **保留不动**。系属是战斗层（连锁/终极），流派是身份层，二者正交 |
| 本命（benming_school） | game.js `state.benming_school`；battle-engine-v2.js:57 `benming:str(state.benming_school,"")` | **既存元素亲和层**，给连锁/被动加成。流派在其上加协同规则（见 §五.4） |
| 本命连锁×1.5 | battle-engine-v2.js:308 `_getComboMultiplier(battle.benming, skill.spell_type)`；:580-583 本命同系 thunder→1.5；:318/:605 `dmg*=1.5`；:643 `_benmingPassiveMult`；:636 妖族+本命同系×1.15 | 流派**不重写**这些，仅在门控与修被动层叠加 |

### 〇.3 取代关系（必须明示，避免双口径）
- **取代 design/6.1「本命流派五选一（雷/火/剑/魂/劫）」（C1 锁定）**：6.1 的"本命流派"在代码中实为 `state.benming_school`（元素亲和），且现有 game.js 的 `chooseBenmingSchool`/`SCHOOL_PASSIVES`/`SCHOOL_NAME` 是"五选一"。**批次5 将重构为四修**（器/体/魂/劫），废弃五选一口径。本命与流派合并为同一次真仙破劫选择（C7，§五.4）。6.1 中"五"的口径作废，统一为"四修"。
- **器修居首、非气修**：依 9.1，四修为「器/体/魂/劫」（器修=封神法宝流特色，居首），不采用早期"气/体/魂/劫"。

## 一、4 修定义

| 修 | 封神定位 | 核心幻想 | 主系 | 代表人物 | 玩法风格 | 一句话 |
|---|---|---|---|---|---|---|
| **器修** | 法宝流（封神招牌） | 一人祭出漫天法宝，轰炸清场 | 器(weapon) | 多宝道人·赵公明·三霄 | 法宝爆发·远程·连锁 | "以器证道" |
| **体修** | 肉身成圣 | 八九玄功，金刚不坏，以力破巧 | 体(body) | 杨戬·哪吒·黄天化 | 近战·反伤·高生存 | "以身证道" |
| **魂修** | 元神流 | 元神出窍，落魂夺魄，控场斩神 | 魂(soul) | 妲己·姚天君·广成子(番天印意境) | 控制·斩杀·暴击 | "以神证道" |
| **劫修** | 气运杀劫 | 斩仙飞刀，趋吉避凶，操弄气运 | 劫(calamity) | 陆压道人·封神榜 | 机制·气运·斩杀线 | "以劫证道" |

**设计原则**：四修对应"输出/生存/控制/机制"四种经典 build 轴，互不碾压（§五.5 平衡）。每修都有清晰的封神人物锚点，确保 lore_anchor 可填。

## 二、内部分支树

> 器修分支为用户指定（9.1）；体/魂/劫分支为**本文提案**，标注〔提案〕，须设计师 refine（见 §十）。
> 结构对称：每修 = 主系 + 2 内部分支 + 1 门内 prestige 跨系分支。

### 二.1 器修（法宝流）
```
器修（主系：器）
├─ 五行〔进阶〕      → 解锁 正五行：金/木/水/火/土（五行法宝万象；火借用现有 fire 系，金木水土为分支内新增元素，非战斗 spell_type）
├─ 混元太极〔高阶〕   → 器系极致：先天至宝流（混元珠/太极图意境），法宝终极强化
└─ 修体〔prestige·门内跨系〕 → 解锁 体系（八九玄功·器修兼修肉身，杨戬式）
```
- **五行**：器修最常见进阶，把"法宝"扩展到"五行法宝"，开放正五行金/木/水/火/土（C3：五行是分支内部进阶体系，非战斗 spell_type；火借用现有 fire 系，五行相生相克为器修专属机制）。
- **混元太极**：高阶纯器路线，不扩系，专注把器系法宝/终极做到极致。
- **修体**（prestige）：高门槛，器修兼修肉身（八九玄功原则——跨系是荣耀而非自由），开放体系槽位。

### 二.2 体修（肉身成圣）〔提案〕
```
体修（主系：体）
├─ 玄功〔进阶〕      → 八九玄功/九转玄功：体暴击+变化（攻击型肉身）
├─ 金身〔进阶〕      → 金刚不坏/法天象地：减伤+巨大化（防御型肉身）
└─ 修器〔prestige·门内跨系〕 → 解锁 器系（体修法宝：哪吒乾坤圈/风火轮式）
```

### 二.3 魂修（元神流）〔提案〕
```
魂修（主系：魂）
├─ 出窍〔进阶〕      → 元神出窍：元神离体额外攻击（每战限次）
├─ 惑心〔进阶〕      → 幻术/落魂：控制命中+控制时长（控场型）
├─ 毒〔进阶·C4〕     → 毒蚀神魂：持续伤害+侵蚀+削弱（封神·吕岳瘟部/余化化血神刀/截教毒术）
└─ 修劫〔prestige·门内跨系〕 → 解锁 劫系（魂涉气运：惑心+气运双修）
```
- **毒**（C4）：魂修·毒分支，毒蚀神魂（持续伤害/侵蚀/削弱），封神锚点=吕岳瘟部/余化化血神刀/截教毒术。毒为分支内元素（魂系框架内），非新战斗 spell_type。

### 二.4 劫修（气运杀劫）〔提案〕
```
劫修（主系：劫）
├─ 斩仙〔进阶〕      → 斩仙飞刀（陆压）：斩杀线（敌人低血直接斩杀）
├─ 气运〔进阶〕      → 趋吉避凶：离线收益+掉落气运（辅助/经营型）
└─ 修魂〔prestige·门内跨系〕 → 解锁 魂系（劫涉魂魄：斩仙+落魂双修）
```

### 二.5 分支解锁层级表（基线〔待校准〕）
| 分支类型 | 解锁层级 | 附加条件 |
|---|---|---|
| 主系 | 真仙破劫成功（zx，约 50/100 节点） | 择派即得 |
| 内部分支（进阶） | 金仙（jx） | 修专属条件（见 §五.3） |
| 内部分支（高阶·混元太极） | 太乙（ty） | 特定机缘/法宝 |
| prestige 跨系分支 | 大罗（dl） | 特定跟脚+机缘+同伴（八九玄功原则，高门槛） |

## 三、门控规则

### 三.1 择派时机与生命周期
1. **试验期（炼气→真仙破劫前）**：无流派门控，全部术法/技能可学可用（=现状）。玩家自由试 6 系，为择派做信息准备。
2. **择派点（真仙破劫成功后）**：弹出「择派仪式」，四修中选一。选择写入 `state.liupai.chosen`，记录 `chosen_at_realm`。**一世不可逆**。
3. **精深期（真仙→大罗）**：按 §二.5 层级逐步解锁内部分支与 prestige 分支。
4. **转世重选**：仅"转世"（终局/大劫机制，远期）可清空 `state.liupai` 重新择派——这是多周目核心驱动。当前版本不可逆。

### 三.2 门控对象（流派影响哪些内容）
| 对象 | 门控方式 |
|---|---|
| 术法（spell_table） | 按 spell_type 与"修+分支"映射门控（§四） |
| 技能（skill_table，战斗槽） | 按 spell_type 门控；非本修系槽位灰显 |
| 法宝（treasure_table） | 不硬门控，但"流派亲和"法宝享加成（§五.4） |
| 神通（combo_ultimate） | 终极按系门控：仅本修系（含分支系）可触发对应终极 |
| 事件/机缘（event_table） | 分支机缘/prestige 机缘挂流派标签，仅对应修可见 |
| 破劫文案 | 真仙破劫 success_text 注入择派仪式 |

### 三.3 prestige 分支门控（八九玄功原则）
跨系**不是自由转系**，而是门内高门槛荣耀路线：
- 须先满本修主系 + 至少 1 内部分支；
- 须特定**跟脚**（如器·修体需"灵明石猴/仙体"类跟脚）+ 特定**机缘**（如"八九玄功残卷"）+ 特定**同伴**（如杨戬同行）；
- 解锁后开放**一个**跨系槽位，不改变主修身份（器修仍是器修，只是兼修体）。
- 设计意图：让"全修"成为传说级成就，而非默认路径，保住流派身份的稀缺感与 lore 厚度。

## 四、术法按系门控

### 四.1 系属分布与元素体系架构（C3）
**战斗系（spell_type，引擎地基，不动）**：体/雷/火/器/魂/劫 6 系。连锁×1.3/三连终极/本命×1.5 全挂在这 6 个 spell_type 上。
- skill_table（战斗槽技能，30）：含全部 6 系。
- spell_table（术法层，23）：thunder 5 / fire 5 / weapon 5 / soul 4 / calamity 4 = 23，无体系（体系活在 skill_table）。
- 门控统一以 spell_type（6 系）为键，跨两表生效。

**分支内元素（非战斗 spell_type，C3/C4）**：五行（金/木/水/火/土）是器修·五行分支的内部进阶体系，毒是魂修·毒分支的内部体系。它们**不新增战斗 spell_type**（避免战斗系扩成 11 系稀释连锁/引擎大改），而是分支内的进度/专属机制层：
- 器修·五行：在器系（weapon）框架内修金木水火土五行法宝，五行相生相克做成器修专属连锁/克制机制（火借用现有 fire 系，金木水土为分支内新增标签）。
- 魂修·毒：在魂系（soul）框架内修毒术（持续伤害/侵蚀/削弱）。
- 此架构绕开数值台账 §1.3 阻塞项（雷火器魂劫的生克映射），把五行生克限定在器修·五行分支内部。

### 四.2 修→可用系 映射表
| 修 | 主系（择派即得） | 分支解锁系 | prestige 解锁系 | 永远不可用 |
|---|---|---|---|---|
| 器修 | 器 | 五行→金/木/水/火/土（分支内元素，C3）；混元太极→（仍器，强化） | 修体→体 | 魂·劫 |
| 体修 | 体 | 玄功/金身→（仍体，强化） | 修器→器 | 雷·火·魂·劫 |
| 魂修 | 魂 | 出窍/惑心→（仍魂，强化）；毒→毒术（分支内元素，C4） | 修劫→劫 | 体·雷·火·器 |
| 劫修 | 劫 | 斩仙/气运→（仍劫，强化） | 修魂→魂 | 体·雷·火·器 |

> 说明（C5 非对称已锁定）：只有**器修**通过"五行"分支横向扩元素（金木水火土，分支内非战斗系），这是 9.1 指定的器修特色（法宝万象）；魂修经"毒"分支获毒术（分支内元素，C4）；体/劫二修内部分支纵向精深本系，跨系仅靠 prestige。器修=唯一大幅横向扩者=封神招牌，形成难度梯度（器修专家向全元素 / 体魂劫新手友好单系）。

### 四.3 门控判定（落码逻辑）
```
canUseSpell(liupai, spell_type):
  if liupai.chosen == null: return true            # 试验期无门控
  native = 主系(liupai.chosen) ∪ 分支解锁系(liupai.branch) ∪ prestige系(liupai.prestige)
  return spell_type in native
```
- 配招界面（battle-ui-v2 renderSlotConfig）：非 native 系的技能/术法**灰显+锁图标**，不可拖入槽位。
- 学习界面：非 native 系术法显示"需 X 修 / X 分支"。

### 四.4 对连锁/终极的影响
- **连锁（同系相邻×1.3）**：引擎按 spell_type 判定，不变。流派只限制"你能放哪些系进槽"，不改变连锁算法。
- **三连终极**：仅本修 native 系可凑齐三连触发终极；他修系（试验期遗留/未清槽）在择派后被门控清出。
- **本命协同**：见 §五.4。

### 五.4 ×1.5 本命（C7：本命与流派合并）
**C7 锁定**：本命（benming_school）与流派=**同一次真仙破劫(bt_003)选择、一世不可逆**（复用现有 game.js:1298 `_maybeTriggerBenming` 触发 + `chooseBenmingSchool` 不可逆逻辑）。玩家真仙破劫成功后弹择派仪式，选四修之一，**本命系即流派主系**（不再分两次选）。
- 因此本命系恒=流派主系，本命加成恒为 **×1.5**（强化档）；原"本命系∉流派→×1.0 兜底"不再需要（仅转世重选前过渡态可能用到）。
- 引擎现状：battle-engine-v2.js:318/:605 本命同系 `dmg*=1.5`、:580-583 `_getComboMultiplier` 本命同系强化、:636 妖族+本命同系×1.15。流派被动在此之上叠加（§五.1）。
- 本命法宝（treasure）：法宝 `related_spell_type` 与流派主系一致时，享法宝流派亲和加成（§六）。
- 重构（批次5，C1）：把现有"五选一" `SCHOOL_PASSIVES`/`SCHOOL_NAME` 改为四修；`chooseBenmingSchool` 写入 `state.liupai.chosen`（本命与流派合一）。

### 五.5 平衡原则
- 四修定位为**输出(器)/生存(体)/控制(魂)/机制(劫)**，PVE 各有最优场景（Boss 战器/体优，持久战魂优，经营/气运劫优），无全能修。
- prestige 分支提供"补短板"能力（器修补生存、体修补输出），但高门槛使其为锦上添花而非必需。
- 数值校准锚点参照 design/8.0（炼气 DPS 200-300 vs Boss HP 500-1000，3-5 轮）逐境缩放。
